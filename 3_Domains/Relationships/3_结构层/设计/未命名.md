# 人际认知系统 需求与设计文档 v0.2

## 1. 文档定位

- 文档类型：需求规格 + 概念性设计
- 面向对象：后续系统化实现（数字化工具 / 纸质系统）时的设计与拆解
- 抽象层级：关注框架与关键维度，不展开到具体话术或 UI

---

## 2. 问题定义与边界

### 2.1 问题定义

- 当前人际相关决策高度依赖即时情绪与创伤反射
- 关系结构与生存资源（居住、现金流）强绑定，单点失败风险高
- 同类事件反复出现，每次都需要从零分析，形成高强度精神内耗

### 2.2 解决对象

- 对象：以“我”为中心的关系网络及其对生存 / 情绪的影响
- 范围：威胁感知、关系评估、行为选择、结构调整四个环节

### 2.3 非目标（边界）

- 不试图解决所有心理问题和依恋创伤
- 不提供通用的社交技巧库或讨好模板
- 不以“让他人更爱我”为目标，而以“降低损耗、提升选择权”为目标

---

## 3. 第一性原理与设计原则

### 3.1 第一性原理

- 人是自利系统：行为优先服务于自身利益与情绪舒适
- 关系是交换结构：资源、情绪、时间、控制权在结构中流动
- 安全感来自结构：可替代性 + 资源独立度 + 边界清晰度
- 情绪是信号，不是指令：决策必须经过显性化的评估流程

### 3.2 设计原则

- 框架优先：先构建稳定框架，再填充个案内容
- 生存优先：在冲突价值时，优先保证生存与基本安全
- 降维简化：有限精力下，采用少量可复用的规则而非复杂策略
- 可执行：每个输出必须能在当前资源约束下落地

---

## 4. 目标与指标

### 4.1 总体目标

- 将“人际决策”从情绪驱动迁移到系统驱动
- 在关键关系上降低情绪绑架程度，提高结构安全度

### 4.2 关键维度指标（方向性）

- 损耗维度：人际反刍时间、冲突后恢复时长
- 安全维度：单点依赖程度、可替代路径数量、现金与居住缓冲
- 主动性维度：主动提要求比例、主动结构调整次数
- 结构维度：关系层级分布、资源集中度

---

## 5. 核心概念与对象

### 5.1 实体

- 人：我、家庭成员、合作方、一般社交对象
- 关系：人与人之间的持续连接，带有类型与权重
- 事件：触发决策的具体情境（话语、行为、决策点）
- 资源：居住、金钱、信息、人脉、时间、情绪能量

### 5.2 关键维度

- 威胁等级：0–5，对生存 / 重大资源的潜在影响
- 依赖度：该关系对关键资源的绑定程度
- 可替代性：若关系终止，找到替代方案的难度
- 情绪负荷：与该关系交互后产生的情绪消耗
- 控制权比例：谁在关系中拥有决策主导权

---

## 6. 能力矩阵（系统应提供的能力）

### 6.1 感知与记录能力

- 捕捉触发事件：记录关键对话、行为与自己的即时反应
- 标记维度：为事件打上关系类型、威胁等级、依赖度等标签

### 6.2 评估与评分能力

- 将复杂情绪拆解为：事实 / 感受 /推测 / 证据
- 对关系进行周期性“体检”：成本、收益、风险、替代性

### 6.3 决策与策略能力

- 在有限策略集合中选择：延迟、降级关系、明确边界、交换条件、退出
- 根据威胁等级与资源约束，给出推荐策略组合

### 6.4 结构调整能力

- 识别单点依赖：找出对单一人的关键资源绑定
- 制定替代路径：为住房、收入、情感支持等设计备份方案

### 6.5 复盘与迭代能力

- 记录执行结果：实际发生了什么、与预期差异
- 调整规则：基于实际效果修正阈值与策略选择逻辑

---

## 7. 系统流程视角

### 7.1 决策流程主线

- 输入：事件 + 当前关系状态 + 资源约束
- 步骤：
  - 感知：记录事实与情绪
  - 评估：威胁评分 + 成本收益评估
  - 决策：在策略集合中选择可行方案
  - 行动：执行具体行为
  - 复盘：记录结果，更新关系与规则
- 输出：本次策略选择 + 关系状态更新 + 学到的规则

### 7.2 时间维度

- 即时决策：面对当下冲突或暗示时的选择
- 短期调整：几周内对关系频率 / 边界的调整
- 中长期结构：对居住、收入、支持系统的结构性规划

---

## 8. 模块划分（概念设计）

### 8.1 关系建模模块

- 输入：人、关系类型、资源绑定信息、互动频率
- 处理：为每段关系维护一组核心维度（威胁、依赖、可替代性等）
- 输出：关系清单 + 关系雷达图 / 分层视图

### 8.2 威胁与资源评估模块

- 输入：事件、对方行为与历史记录、当前资源状态
- 处理：计算威胁等级，评估潜在损失、恢复难度与替代路径
- 输出：威胁评分 + 建议防御级别

### 8.3 情绪-事实分离模块

- 输入：一次强烈情绪体验
- 处理：拆分为事实 / 感受 / 推测 / 证据四栏
- 输出：清晰事实表 + 被标记的认知偏差

### 8.4 行为策略选择模块

- 输入：威胁评分、关系类型、资源约束
- 处理：在有限策略集合中筛选当前可执行方案
- 输出：1–2 个推荐策略 + 简要执行条件

### 8.5 关系成本核算与结构调整模块

- 输入：一段时间内的互动记录与资源变化
- 处理：计算精神 / 时间 / 经济成本与控制权比例、替代难度
- 输出：结构性建议（继续 / 降级 / 准备退出）及潜在替代路径

### 8.6 复盘与规则更新模块

- 输入：实际执行结果与主观感受
- 处理：识别策略效果与偏差，微调评分权重与决策阈值
- 输出：更新后的规则集与注意事项

---

## 9. 典型场景模板

### 9.1 高威胁暗示（如“你可以搬走”）

- 主要维度：威胁等级、居住依赖度、可替代路径
- 目标：从“恐慌”切换到“看结构”，评估真实损失与备选方案

### 9.2 想提要求但害怕

- 主要维度：最坏真实损失、当前资源缓冲、关系类型
- 目标：判断是否在生存阈值之内，若是，则按边界类策略执行

### 9.3 长时间反刍同一关系

- 主要维度：是否有新信息、是否涉及结构性风险
- 目标：将“无新信息”的反刍归入系统流程并中止循环

---

## 10. 实现约束与演进

### 10.1 现实约束

- 精力有限：每次使用流程步骤数必须可控
- 资源脆弱：所有建议必须在当前资源下可执行
- 高敏感：避免过于冷硬的语言增加二次打击

### 10.2 演进路线（方向）

- v0：纸笔 / 笔记工具中的手工流程与表格
- v1：数字化模板（表单 + 评分 + 决策建议）
- v2：关系网络与资源结构的可视化 + 自动提示
