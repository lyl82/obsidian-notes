# 结构层：人际输入端设计 - 索引

## 1. 模块目的

- 把“人际关系”从被系统分配的随机样本，改写为主动设计的目标样本。
- 建立一套可反复使用的输入端系统，而不是临时性的“交朋友技巧”。
- 与判断层的公众场景、自我价值防护等 SOP 联动，形成完整的人际系统。

## 2. 模块结构总览

本模块由五个核心行动文件组成：

1. 《人际输入端设计-总览SOP》
2. 《人际输入端-目标人画像模板》
3. 《人际输入端-获取场景地图》
4. 《人际输入端-关系漏斗设计》
5. 《人际输入端-关系盘点流程》

建议使用顺序：

1. 先通读《总览SOP》，理解整体流程。
2. 使用《目标人画像模板》明确自己需要什么样的人。
3. 用《获取场景地图》设计自选场景，而不是只依赖系统分配场景。
4. 在实际互动中按《关系漏斗设计》推动关系升级或自然退场。
5. 每 3 个月根据《关系盘点流程》调整整体人际资产配置。

## 3. 与现有系统的关系

- 与 0_核心认知原则：
  - 对应“自我价值缓冲原则”“镜像式对等原则”等，用于约束投入边界。
- 与 1_人档案层：
  - 人档案中记录重要对象，输入端设计决定“谁有资格进入人档案”。
- 与 2_判断层：
  - 《公众场景-自我价值防护SOP》：处理高曝光场景的价值防护。
  - 《通用人际策略规则》：提供通用原则。
  - 本模块：负责“人从哪来、要什么样的人”的供应链设计。

## 4. 快速使用指引

如果当前时间有限，可以按以下最小可行路径执行：

1. 打开《人际输入端-目标人画像模板》，先填写出 1–2 个关键人画像。
2. 打开《人际输入端-获取场景地图》，为每个画像至少写出 1–2 个可能出现的场景。
3. 打开《人际输入端-关系漏斗设计》，把身边的 5 个重要对象定位到漏斗中的某一层级。
4. 打开《人际输入端-关系盘点流程》，做一次轻量级盘点，决定：增持、持有或减持。

之后再根据需要补充细节，反复迭代。
