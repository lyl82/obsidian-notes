# 结构层：人际输入端设计 - 总览 SOP

## 1. 适用范围

- 当前主要人际来源为：
  - 家庭、同学、同事等“系统分配关系”。
  - 关系多为被动形成，缺少主动选择。
- 感受到的问题：
  - 对“朋友”概念有怀疑，认为长期稳定朋友极少。
  - 关系质量波动大，自我价值容易受到外部评价拖拽。
  - 不清楚“我要什么样的人”，只是在“认识了谁”中被动选择。

目标：从“系统默认分配的人际关系”转向“主动设计的人际输入端系统”。

## 2. 核心思路

把“人际输入端”设计为一个完整供应链：

1. 明确我要什么样的人（目标样本，而不是随机样本）。
2. 设计在哪些场景遇见他们（自选场景，而不是只依赖系统分配场景）。
3. 用关系漏斗推进或退出（弱连接 → 轻合作 → 长期伙伴）。
4. 定期盘点和重配资源（增持 / 持有 / 减持）。

对应文件：

- 《人际输入端-目标人画像模板》
- 《人际输入端-获取场景地图》
- 《人际输入端-关系漏斗设计》
- 《人际输入端-关系盘点流程》

## 3. 执行总流程

整体分为四个阶段：

1. 设计阶段：写清楚“我需要什么样的人”。
2. 获取阶段：设计并进入自选场景，建立弱连接。
3. 漏斗阶段：根据行为与感受，决定谁往前推进、谁自然淡出。
4. 盘点阶段：每 3 个月复盘一次整体人际配置。

建议使用节奏：

- 第一次执行：预留 2–3 个番茄钟，完成最小可行版本。
- 之后：每月微调，每季度做一次完整盘点。

## 4. 阶段一：设计目标人画像

### 4.1 行动步骤

1. 打开《人际输入端-目标人画像模板》。
2. 至少设计 2 个画像，例如：
   - 一起做长期项目的合伙型朋友。
   - 可以深度聊世界观的思想同路人。
3. 对每个画像，填写以下维度：
   - 价值观：对人、对事、对世界的基本判断。
   - 能力 / 资源：在某些方面比你更强或互补。
   - 人生阶段：处在相近或兼容的发展阶段。
   - 互动方式：沟通风格、冲突处理方式。
   - 安全底线：不越界、不反复消耗、自我约束能力。

### 4.2 输出标准

- 每个画像不需要完美，只需做到：
  - 能用一句话描述。
  - 能列出 3–5 个“必须有”和 2–3 个“坚决不要”。

## 5. 阶段二：设计获取场景

### 5.1 行动步骤

1. 打开《人际输入端-获取场景地图》。
2. 对每个画像，思考：
   - 这类人通常会出现在什么具体场景？
   - 哪些是线下场景，哪些是线上场景？
3. 把场景归类到以下几类：
   - 能力型场景：行业社群、专业会议、项目协作平台。
   - 兴趣型场景：兴趣班、同好会、线下活动。
   - 价值观型场景：读书会、公益项目、小范围讨论组。
   - 生活方式型场景：固定运动局、早起群、习惯养成小组。
4. 为每个场景设置“最低出现频率”，例如：
   - 每周至少一次。
   - 每月至少两次。

### 5.2 输出标准

- 每个目标画像至少对应 1–2 个可落地的场景。
- 这些场景是你现实中有机会、也愿意出现的，而不是幻想场景。

## 6. 阶段三：搭建关系漏斗

### 6.1 行动步骤

1. 打开《人际输入端-关系漏斗设计》。
2. 把关系分为四层：
   - 初次接触。
   - 弱连接。
   - 轻合作 / 深度对谈。
   - 长期伙伴 / 关键少数。
3. 为每一层写清楚：
   - 典型行为：你和对方会做什么。
   - 观察指标：你看什么来决定是否进入下一层。
   - 升级动作：具体怎么从这一层迈向下一层。
   - 退出动作：什么情况下停在当前层，或自然淡出。
4. 用这个漏斗对身边的 5–10 个人进行一次标记：
   - 标注当前层级。
   - 决定下一步动作：升级、保持或减持。

### 6.2 输出标准

- 至少完成一次“对 5 人的漏斗定位”。
- 对每个人写下一句“下一步动作”，例如：
  - “下次见面尝试聊一次价值观层面的议题。”
  - “保持礼貌，不再主动约见，由关系自然淡出。”

## 7. 阶段四：关系盘点与重配

### 7.1 行动步骤

1. 打开《人际输入端-关系盘点流程》。
2. 每 3 个月进行一次盘点，分三类列出重要关系：
   - 系统分配关系：家人、同学、同事等。
   - 主动选择关系：通过自选场景刻意认识的人。
   - 历史遗留关系：已经不再适配现在的你，但仍在消耗资源的。
3. 对每个人只回答三个问题：
   - 和 TA 相处后，整体能量是正 / 负 / 中性？
   - 是否多次跨过你的底线？
   - 从未来 3 年看，你希望这段关系是升级、维持还是淡出？
4. 给出一个明确决策：
   - 增持：提高接触频率，增加共同经历。
   - 持有：维持现有频率，不做额外投入。
   - 减持：降低接触频率，撤出情绪与时间投入。

### 7.2 输出标准

- 完成一次盘点后，你能清晰回答：
  - 哪 3–5 个人是你未来要重点增持的？
  - 哪些人只保留基本礼貌，不再额外投入？
  - 哪些人可以允许关系进入“历史归档”状态？

## 8. 与公众场景、自我价值防护的联动

- 在公众 / 高曝光场景中，优先问自己：
  - 这个对象，是系统分配的，还是主动选择的？
- 对系统分配对象：
  - 主要目标是自我价值防护，而不是深度关系建设。
  - 使用《公众场景-自我价值防护SOP》保护自我价值。
- 对主动选择对象：
  - 使用本模块的关系漏斗与盘点流程，决定是否升级投入。

通过这套总览 SOP，你可以把“交朋友”从模糊的感受问题，转化为一套可执行、可迭代的输入端系统。
