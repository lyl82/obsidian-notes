# 结构层：人际输入端 - 关系漏斗设计

## 1. 使用说明

- 目的：用一个清晰的漏斗，管理关系的升级、保持或淡出。
- 核心原则：
  - 大多数人停留在“弱连接”是正常的。
  - 只有少数人进入“长期伙伴 / 关键少数”层级。
  - 不再强求把“系统分配的人”都变成“朋友”。
- 输出物：
  - 一份四层关系漏斗定义。
  - 对身边 5–10 人的当前层级标注与下一步行动。

## 2. 四层关系定义

### 2.1 第一层：初次接触

- 特征：
  - 只见过一两次面，信息很少。
  - 多在公开场景或群聊中短暂互动。
- 你的最低行动：
  - 简短自我介绍：
    - “我最近在做 / 关注 xx，你刚刚说的 yy 挺有意思。”
  - 在结束时留一个轻量连接点（视情况决定是否留联系方式）。
- 观察要点：
  - 是否基本尊重人、不无礼。
  - 是否有一点点共同话题的可能。

### 2.2 第二层：弱连接

- 特征：
  - 彼此知道大致背景，偶尔在信息流中看到。
  - 时间跨度可以较长，但互动频率不高。
- 你的行动：
  - 每月或每两月，有一次轻触达：
    - 转发一条对方可能感兴趣的信息并简短说明。
    - 向对方反馈一件与他相关的正向观察。
  - 见面时简单更新彼此近况。
- 观察要点：
  - 是否也会主动回应你，而不是单向消耗。
  - 是否守约、不反复迟到或放鸽子。

### 2.3 第三层：轻合作 / 深度对谈

- 特征：
  - 出现过1–2次共同完成某件事情的经历，或有过 1–2 次深度对谈。
- 你的行动：
  - 主动发起一次小型合作：
    - 一起完成一个小项目、一篇内容、一场活动。
  - 或约一次有明确主题的深度对话：
    - 如：聊各自的选择逻辑、失败经历、长期目标。
- 观察要点：
  - 面对分歧时的处理方式：
    - 会不会直接攻击你的人，而不是共同面对问题。
  - 情绪稳定程度：
    - 是否容易情绪失控、冷暴力或翻旧账。
  - 对时间与承诺的态度：
    - 是否兑现约定，有问题时能否提前说明。

### 2.4 第四层：长期伙伴 / 关键少数

- 特征：
  - 经历过多次环境变动后仍保持联系。
  - 在关键节点上互相支持过。
  - 可以在一定范围内托付部分重要信息或共同决策。
- 你的行动：
  - 主动规划长期共同项目或节律：
    - 每年一次深度对谈。
    - 每季度一次共同复盘。
  - 对对方的人生关键事件保持一定程度的关注。
- 观察要点：
  - 是否能把对方当成“长期存在”的一部分，而不是阶段性工具。
  - 对方是否也在为关系投入时间与精力。

## 3. 升级与退出规则

### 3.1 升级规则

- 从初次接触 → 弱连接：
  - 至少有一次舒适的互动，对方基本尊重你。
  - 你对继续了解对方有“好奇 + 安全感”。
- 从弱连接 → 轻合作 / 深度对谈：
  - 你看到对方在某方面的能力或稳定性。
  - 对方表现出一定程度的可靠性和真诚。
- 从轻合作 → 长期伙伴：
  - 经历过一次以上的困难情境仍能互相尊重。
  - 感觉到双方都愿意承担一定关系成本。

### 3.2 退出 / 减持规则

- 以下情况出现 2 次及以上，可考虑降低层级或淡出：
  - 反复踩你的底线且不愿调整。
  - 长期只在情绪低落时找你，且不愿意自己承担责任。
  - 对你表现出明显的轻蔑、利用或工具化态度。
- 退出动作：
  - 降低接触频率：
    - 减少主动联系，不再发起约见。
  - 调整内部赋值：
    - 从“朋友 / 重要对象”调整为“普通关系 / 历史关系”。
  - 必要时设置明确界限：
    - 用简短清晰的语言说明你能接受和不能接受的部分。

## 4. 实际操作：给身边 5–10 人标注层级

### 4.1 列出名单

- 先不分类，直接写下你近期经常想到或互动的 5–10 个人。

### 4.2 标注当前层级

- 对每个人，只问：
  - 最近一年，你们的实际互动更符合哪一层的描述？
  - 若介于两层之间，以“较低”的一层为准。

### 4.3 决定下一步动作

- 对每个人写一句话：
  - 下一步想让关系：
    - 升级：
      - 具体动作：
    - 维持：
      - 具体动作：
    - 淡出：
      - 具体动作：

完成这一轮后，你就有了一份可执行的“关系漏斗快照”，之后可以每 3 个月更新一次。
