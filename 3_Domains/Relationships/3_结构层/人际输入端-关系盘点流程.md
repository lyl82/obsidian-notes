# 结构层：人际输入端 - 关系盘点流程

## 1. 使用说明

- 目的：定期检查并调整整体人际关系配置。
- 原则：
  - 承认大部分关系是阶段性、环境绑定的。
  - 把情感投入和时间投入当作有限资源，进行再分配。
- 建议节奏：
  - 每 3 个月进行一次完整盘点。
  - 如遇重大生活变动（换城市、换工作等），可以临时加做一次。

## 5. 做出“增持 / 持有 / 减持”决策

### 5.1 决策规则

- 增持：
  - 能量多为正或持平。
  - 无明显底线问题。
  - 和你的目标人画像匹配度较高。
- 持有：
  - 能量大致持平。
  - 底线基本安全。
  - 主要作用是维持日常链接，不是关键投资对象。
- 减持 / 退出：
  - 能量持续偏负。
  - 有严重或反复的底线问题。
  - 与当前或未来 3 年的人生方向明显不匹配。

### 5.2 具体执行动作

- 对被标记为“增持”的人：
  - 在接下来 3 个月：
    - 主动增加 1–2 次高质量互动。
    - 寻找一次轻合作机会或深度对谈机会。
- 对被标记为“持有”的人：
  - 保持当前频率，不额外投入时间和情绪。
  - 接受这类关系是“正常背景噪音”，不是核心资产。
- 对被标记为“减持 / 退出”的人：
  - 主动降低接触频率：
    - 减少主动联系次数。
    - 必要时减少在同一场景中出现的机会。
  - 在内部重新赋值：
    - 不再在心里把 TA 归类为“朋友”或“重要关系”。
  - 若有必要，设置明确界限：
    - 用简短而清晰的方式表达你的界限和期望。

## 7. 复盘与迭代

- 每次盘点后，可以在下次盘点时多看两点：
  - 上次决定增持的人，是否真的带来了更多正向反馈？
  - 上次没有下决心减持的人，这 3 个月是否继续消耗你？
- 根据实际体验微调：
  - 目标人画像。
  - 获取场景。
  - 漏斗升级 / 退出规则。

通过这套盘点流程，你可以定期校准自己的人际“投资组合”，减少随机性伤害，逐步增加主动选择的成分。
