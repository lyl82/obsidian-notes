# 判断层：通用人际策略规则 v0.1

## 一、策略总目标

- 在当前硬件与人际基态约束下，减少灾难性的人际误判和能量破产。  
- 用一套简单可执行的规则，指导“对谁投入多少”“何时设边界或退出”。  
- 默认资源有限（时间、注意力、情感能量），关系需要被当作长期资产管理。  

## 二、适用范围

- 日常的家人、同学、同事、普通朋友、网络熟人等非极端关系。  
- 不适用于：暴力、重大利益冲突、极端控制型关系等，需要更高优先级安全策略。  

## 三、关系投入等级定义

- L0 观察状态  
  - 陌生人、泛泛之交，仅维持礼貌和低成本互动。  
  - 不主动输出隐私、不承担对方情绪。  

- L1 轻度投入  
  - 偶尔聊天、点到为止的分享，可以互相提供简单信息或帮助。  
  - 可在低风险话题上适度真诚，但不过度暴露脆弱面。  

- L2 中度投入  
  - 有一定信任基础，愿意定期联系、分享部分重要近况。  
  - 可以有限度承接对方情绪，但需要明确自身边界与时间。  

- L3 高度投入  
  - 重要关系：少数家人、深度朋友或稳定合作伙伴。  
  - 可以在双方同意的前提下，承担较高情绪和资源投入，但必须符合“防破产优先”。  

## 四、提升投入等级的基本规则

1. 信息足够规则  
   - 从 L0/L1 提升到更高等级，必须满足：  
     - 至少 2–3 次独立场景下的稳定正向体验，而不是一次性好感。  
     - 对方在不同状态（顺利/一般/有压力时）的表现有基本样本。  

2. 对等性规则  
   - 只有当“付出与获得”在大致同一数量级时，才考虑提升投入。  
   - 若长期为单向输出（你持续承担情绪、时间、资源），默认不升等级。  

3. 稳定边界规则  
   - 在现有等级下，对方能基本尊重你的时间、节奏和拒绝权。  
   - 若对方经常无视边界或道德绑架，禁止提升投入等级。  

4. 多源验证规则  
   - 若判断高度依赖对方自述，应尽量通过行为、第三方反馈或长期表现进行交叉验证。  
   - 对方自我叙事与现实行为长期不符时，优先保持在 L1/L2。  

## 五、降低投入或设边界的触发规则

1. 高消耗信号  
   - 与其互动后，经常出现以下之一：  
     - 明显身体紧绷与疲惫；  
     - 长时间反复回放对话、陷入自我否定；  
     - 影响睡眠或工作专注。  
   - 若连续出现 3 次以上，可视为需要“主动降级”的信号。  

2. 结构性不尊重  
   - 频繁轻蔑、否定、贬低你的能力或人格；  
   - 持续忽视你的边界与拒绝；  
   - 在公共场合反复让你处于羞辱或尴尬位置。  
   - 出现上述情况时：  
     - 先从 L3/L2 降到 L1，减少暴露与投入；  
     - 再根据后续行为决定是否进一步退出。  

3. 价值观核心冲突  
   - 在诚实、对弱者态度、底线行为（欺骗、剥削、暴力等）上存在持续冲突。  
   - 即使对你个人态度尚可，也不宜维持高投入等级。  

4. 非对等责任压缩  
   - 关系中长期要求你承担超出角色的责任（情绪收容、经济支持、无条件可用）。  
   - 若你一旦稍微收回，就引发强烈指责或道德勒索，则需要降级并重设边界。  

5. 自我价值与羞耻触发  
   - 与其互动后，自我价值感多次出现剧烈波动（例如被反复评价为“低价值”“不合格”），并触发强烈羞耻和自我否定。  
   - 若这种触发与对方的稳定行为模式相关，而非个别事件，应降低投入等级，并优先调用自我价值防护流程。  

## 六、退出策略（软退出与硬退出）

- 软退出（适用于风险中等但无严重伤害的关系）  
  - 逐步降低联系频率；  
  - 把话题收窄到低风险、低情绪的范围；  
  - 避免做出新的高投入承诺。  

- 硬退出（适用于明显伤害性或严重超出承载能力的关系）  
  - 明确告知：自己无法继续维持当前强度的关系；  
  - 在必要时减少或切断联系方式；  
 - 若关系不可完全断开（如部分家人或职场上级），则转为最低必要功能性互动。  

## 七、特殊场景策略补充

- 身体与性互动  
  - 身体和性相关互动视为高风险、高杠杆场景，不适用 L0/L1 的默认低风险规则。  
  - 任何此类互动前，应确认：  
    - 当前能量状态在可承受范围内；  
    - 不在严重药物或酒精影响下；  
    - 边界与同意是清晰的。  
  - 互动后需单独复盘：对自我价值、羞耻感和后续人际模式的影响。  

- 家族关系的有限责任模式  
  - 家族成员关系默认具有无法完全退出的现实约束，策略目标从“追求理想亲密”调整为“在可承受范围内维护基本秩序与心身安全”。  
  - 对家族中的长期伤害性模式，优先使用：  
    - 物理距离与互动频率控制；  
    - 心理边界设定（不再向对方求证自我价值）；  
    - 必要时，将关系降级为最低必要功能性互动。  

## 八、日常决策简化流程

针对每一段正在关注的关系，可以定期快速走一遍下面的检查：

1. 现在的投入等级是 L0/L1/L2/L3？  
2. 过去 3 次重要互动的：  
   - 价值感受：获得支持、信息、机会的程度；  
   - 成本感受：能量消耗、焦虑、自我否定的程度。  
3. 综合判断：  
   - 若价值明显高于成本 → 考虑维持或缓慢升级；  
   - 若价值和成本接近 → 维持现级，增加观察数据；  
   - 若成本长期高于价值 → 启动降级或退出流程。  

## 八、与人档案和互动记录的衔接

- 任何投入等级的变动，应在对应“人档案”中简要记录原因。  
- 对单次互动的强烈情绪体验，应优先写入“互动记录”，而不是立刻调整投入等级。  
- 当连续多次互动记录指向同一趋势时，再根据本文件的规则调整关系策略。
