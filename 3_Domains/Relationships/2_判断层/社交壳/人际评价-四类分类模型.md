# 人际评价 - 四类分类模型 v1.0

> 目标：在 10 秒内把对方的输出丢进一个桶里，先分类，再处理。

---

## 1. A 类：事实型评价

**定义：**

- 描述「发生了什么 / 没发生什么」的客观信息。
- 通常包含时间、次数、结果、具体行为等要素。

**示例：**

- “你昨天迟到了 20 分钟。”
- “你这份报告比约定时间晚交了两天。”
- “这段时间你很少在群里说话。”

**识别提示：**

- 可以追问一句“具体是什么事？”时，对方能给出明确、可验证的事情。
- 不带「你这个人怎样」的评价词，而是聚焦在事件本身。

---

## 2. B 类：能力判断型评价

**定义：**

- 对你的能力、适配度、胜任程度下结论。
- 典型是在说“你行不行”“你适不适合做这件事”。

**示例：**

- “你不适合做这个工作。”
- “你这种性格不适合带团队。”
- “你根本处理不了这种项目。”

**识别提示：**

- 常见关键词：适合 / 能不能 / 做不好 / 不行。
- 若追问“你指的是哪件事？”时，健康的 B 类应该能指向若干具体行为。

---

## 3. C 类：动机揣测型评价

**定义：**

- 把你「是什么样的人、怀着什么心思」直接定性。
- 用对方的主观感受去解释你的动机与人格。

**示例：**

- “你就是不负责。”
- “你就是懒、根本不在乎这件事。”
- “你就是存心想拖累大家。”

**识别提示：**

- 常见关键词：就是、根本、压根、天生、心术不正、自私。
- 重点落在「你这个人怎样」，而不是「你做了什么行为」。

---

## 4. D 类：情绪发泄型评价

**定义：**

- 对方主要目的是释放情绪，而不是交流信息。
- 用攻击性语言表达愤怒、委屈、厌恶等感受。

**示例：**

- “你真让人恶心。”
- “滚。”
- “懒得跟你说，你这种人没救。”

**识别提示：**

- 逻辑不完整，理由含糊，情绪极强。
- 如果让对方冷静下来重说，他往往会换一套说法。

---

## 5. 混合型与归类原则

- 现实中的话语往往是混合的，例如：
  - “你这么晚交（事实），就是不负责（动机揣测），真让人恶心（情绪发泄）。”

- 归类原则：
  - **按杀伤力最大的一类处理**。
  - 若同时包含 C 和 D，则优先按 C/D 的防御策略来做（边界声明 + 不接球）。

---

## 6. 使用说明

- 分类是为了「选对处理方式」，不是为了在概念上争论。
- 允许模糊判断，只要能大致决定是走 A/B 逻辑还是 C/D 防火墙即可。
- 记住：**90% 的杀伤力来自 C 和 D。**
