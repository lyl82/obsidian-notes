# 人际评价 - 事后复盘模板 v1.0

> 目标：把一次评价事件，转化为一条「行为调整指令」，而不是一条「自我否定结论」。

---

## 1. 复盘触发条件

满足以下任一条件，建议写一条复盘日志：

- 当天因为某句话 / 某个表情情绪波动明显。
- 当场没反应过来，但事后反复想起。
- 同一类型的评价在一周内出现两次及以上。

---

## 2. 单条事件复盘模板

可以每次复制这一小节，在下面填写。

### 2.x 事件标题（自取一个便于记忆的名字）

1. 事件记录（事实层）
   - 时间 / 场景：
   - 对方身份：
   - 对方原话 / 行为（尽量接近原句）：

2. 分类与切割
   - 我现在的分类判断（可多选）：A 事实 / B 能力 / C 动机 / D 情绪
   - 若混合，杀伤力最大的是哪一类：
   - 切割句：  
     - “这是对【什么角色】的一条信号？”  
       例：同事 / 项目负责人 / 伴侣 / 家庭成员……

3. 与人设稳定特征对比
   - 这条信息是否与我设定的稳定特征（高概率行为倾向）冲突？  
     - 是 / 否（简要说明）：
   - 它主要是在攻击我的人格，还是在提示某个「行为模式」的问题？  
   - 去掉对方的情绪之后，这条信息里是否有对我有用的客观信号？  
     - 有的话，具体是什么：

4. 只改动作，不改自我评价

   - 禁止使用的句式（不要写在这里）：  
     - “我是个废物。”  
     - “我就是不行 / 一无是处。”  
     - “我就该被这样对待。”

   - 必须写为「行为调整句」，统一结构为：

     > “在【某种场景】中，下次我会【做出哪一个具体动作】。”

   - 示例（可删）：
     - “在项目进度有风险时，我要提前 2 天主动给出更新，而不是等别人来问。”
     - “在公开场合被质疑时，我先确认事实，再给出当前进度，而不是当场沉默。”

5. 与边界 / 接口风格的调整

   - 这次事件是否说明：  
     - 我的边界声明得太晚 / 太弱？  
     - 我的表达方式让对方误读了我的态度？

   - 如果是，请写出下一次的预设动作，例如：
     - “以后遇到动机揣测，我会更早说出：‘你可以评价我的行为，但别替我定义动机。’”
     - “以后在被情绪型攻击时，我优先选择沉默或结束对话，而不是解释。”

---

## 3. 周 / 月度回顾建议

每周或每月可以抽时间，回顾这一段时间写过的评价复盘日志，问自己：

- 哪些行为调整已经自然化（不再需要刻意提醒）？
- 哪些场景仍然反复出现，说明当前策略不够有效，需要升级？
- 是否有必要：
  - 更新当场处理流程中的默认话术？
  - 增加新的边界声明句式？
  - 写入新的「通用人际策略规则」？

若进行了这些调整，记得在：

- 《人际评价系统-索引.md》里更新版本记录；
- 《人际评价-原则-评价用于校准行为轨迹.md》里补充新的原则或例外情况。
