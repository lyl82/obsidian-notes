# 人际评价 - 当场处理流程 v1.0

> 目标：当下被评价时，有一套「默认脚本」可执行，而不是靠当场情绪乱反应。

## 2. 共同步骤：触发 → 记录 → 分类 → 切割

### 2.1 触发

- 内部信号：  
  - “我感觉自己被否定 / 被攻击 / 有点想解释自己。”
- 一旦出现这些感受，就视为触发条件。

### 2.2 记录原始信息

- 问自己：
  - “对方刚才**具体做了什么**？”
  - “他说的**原话**尽量是什么？”
- 只记录行为与话语，不急着解释动机。

### 2.3 10 秒内分类（参考《人际评价-四类分类模型》）

- 粗略判断：
  - 是否在说客观事实？→ A
  - 是否在说你行不行？→ B
  - 是否在给你贴「什么样的人」的标签？→ C
  - 是否主要是在情绪发泄？→ D
- 若混合，按杀伤力最大的一类处理。

### 2.4 切割（认知防火墙）

- 在脑内强制改写一句话：
  - 从：“他在评价我。”
  - 到：“他在输出一条关于【这个角色】的一条信号。”

- 角色可以是：
  - 工作场景下的同事 / 下属 / 上级
  - 亲密关系中的伴侣 / 家庭成员
  - 社交场景中的参与者

## 3. 各类型的默认回应策略

### 3.1 A 类：事实型 → 校正或承认

**原则：**

- 只处理事实本身，不加情绪、不解释动机、不自责。

**默认话术：**

- 事实正确：
  - “是的，我迟到了。”
- 部分不准确：
  - “不是 20 分钟，是 8 分钟。”

**当场不做：**

- 不解释自己为什么迟到。
- 不在当场展开对自我价值的讨论。

---

### 3.2 B 类：能力判断型 → 要证据或场景

**原则：**

- 把“你不行”拆解为“哪几件事情做得不够好”。

**默认话术：**

- “你指的是哪件事 / 哪几次的表现？”
- “可以具体说说是哪方面让你觉得我不适合吗？”

**后续分支：**

- 若对方说不出具体事例：
  - 在内部把这条评价降级为「情绪型」，当场不再深究。
- 若对方说得出：
  - 把那些具体事件记下来，留到事后复盘日志里处理。

---

### 3.3 C 类：动机揣测型 → 不解释动机，只谈行为

**原则：**

- 动机和人格只由自己来定义，对方只能评价行为。

**默认话术：**

- “你可以评价我的行为，但别替我定义动机。”
- “如果是具体行为让你不舒服，你可以说那件事，我们可以谈行为。”

**注意：**

- 这是边界声明，不是辩论。
- 说完即可收口，不再陷入“我其实不是那样的人”的循环证明。

---

### 3.4 D 类：情绪发泄型 → 不接球

**原则：**

- 任何解释都会变成对方继续发泄的燃料。

**可选动作仅三种：**

- 无回应（沉默 / 不回消息）。
- 转移话题，回到事实或任务：
  - “我们先回到这件事本身……”
- 结束对话：
  - “我先忙到这儿，有事后面再说。”

**不做的事：**

- 不在当场尝试说服对方「讲道理」。
- 不在对方高情绪状态下做自我反省或认罪。

---

## 4. 当场与事后的边界

- 当场流程的目标：
  - 把自己从情绪风暴里「安全撤离」。
  - 最少必要回应，保护边界，给未来的复盘留空间。

- 事后复盘的目标（见《人际评价-事后复盘模板》）：
  - 用更冷静的状态，判断是否需要调整行为模式。
  - 把有用的信息写入自己的行为系统，而不是写入自我评价。
