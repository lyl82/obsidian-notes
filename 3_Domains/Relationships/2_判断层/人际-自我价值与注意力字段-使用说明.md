# 判断层：人际与自我价值 / 注意力字段使用说明

## 1. 目的

- 衔接人际判断系统与自我价值、自我形象系统。  
- 说明新增加字段（自我价值影响、能量模式、注意力与记忆信号）的使用方式。  

## 2. 人档案中的自我相关字段

- 对自我价值的影响：  
  - 用于记录这段关系长期对自我价值感的方向性影响：强化 / 削弱 / 波动不大。  
- 能量模式：  
  - 记录与该人互动后，整体能量倾向是偏正、持平还是偏负。  
- 可接受互动节律：  
  - 粗略标记对这段关系的合理频率，防止在能量不足时过度暴露。  

这些字段不用于道德评判，而用于：  
- 决定在资源有限时优先维护哪些关系；  
- 提醒自己哪些关系需要配套更强的自我价值防护与节律管理。  

## 3. 互动记录中的注意力与记忆字段

- 事件结束后 24 小时内是否反复回想：  
  - 是 / 否，用于识别“进入神经系统”的事件。  
- 回想时主导情绪：  
  - 愉快 / 焦虑 / 羞耻 / 敌意 / 空虚 / 其他。  
- 是否标记为“长期记忆节点”：  
  - 是 / 否，用于未来复盘时快速定位关键互动。  

使用原则：  
- 对强烈回放、强情绪的事件，优先写完整互动记录；  
- 不急于立刻调整关系投入等级，而是让多次记录形成趋势再决策。  

## 4. 与自我系统的接口

- 当某段关系在“对自我价值的影响”字段长期为“削弱”，且注意力字段显示频繁回放时：  
  - 先调用自我价值防护流程（在自我模型文档中定义），再考虑降级关系。  
- 当某段关系长期“强化”自我价值，且能量模式偏正：  
  - 在总体资源允许的前提下，可以作为优先维护或逐步加深的候选。
