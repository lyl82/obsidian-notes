# 判断层：公众场景自我价值防护 SOP

## 1. 适用范围

- 场景类型：
  - 面试、群面、公开演讲、答辩
  - 线上短视频、直播、公众平台发言
  - 任何“被一群人看见、被评价”的场景
- 特征：
  - 协议等级通常在 4–5
  - 群体社会伦理标签多为：职场 / 陌生人 / 公众
  - 自我价值感、羞耻感、恐惧感容易被强烈触发

目标：在高曝光场景下保护自我价值和能量，不让单次事件晋级为“我是谁”的结论。

关联文档：

- 判断层：人际判断模型字段说明
- 判断层：人际与自我价值 / 注意力字段使用说明
- 核心认知原则：自我价值缓冲原则、对称人性原则、延时判断原则

## 2. 关键字段联动

- 群体社会伦理标签：
  - 职场 / 公众 / 陌生人
- 协议等级：
  - 4：面试、重要会议、正式评估
  - 5：公开发言、公开视频、长期留存内容
- 动力层：
  - 常见驱动：恐惧驱动、责任驱动
  - 常见主要逃避：失败、羞辱、被评判、被忽视
- 人档案中的自我相关字段：
  - 对自我价值的长期影响：强化 / 削弱 / 波动不大
  - 能量模式：偏正 / 持平 / 偏负
  - 可接受互动节律：公众场景的合理频率
- 互动记录中的注意力与记忆字段：
  - 事件结束后 24 小时内是否反复回想：是 / 否
  - 回想时主导情绪：愉快 / 焦虑 / 羞耻 / 敌意 / 空虚 / 其他
  - 是否标记为长期记忆节点：是 / 否

## 3. SOP 总览

分为三个阶段执行：

1. 进入前：识别场景并设置自我价值保护
2. 场景中：聚焦任务，限制自我攻击
3. 结束后 24 小时内：记录、复盘、必要时调用自我价值防护流程

对应流程图见同目录 Mermaid 文件。

## 4. 阶段一：进入前

### 4.1 场景识别

- 问自己：
  - 这次属于哪一类公众场景？面试 / 群面 / 公开发言 / 视频曝光等
  - 群体社会伦理标签是什么？职场 / 陌生人 / 公众
  - 协议等级是多少？通常预设为 4 或 5

### 4.2 明确本次目标

- 把目标从“证明我值不值得”改写为：
  - 这是一次练习和收集反馈的机会
  - 这是一次测试当前技能和准备程度的机会
  - 这是一次探索适配度的过程，而不是终局裁决

可以用一句话总结本次目标，例如：

- “我来获取一组关于自己表现的反馈。”
- “我来练习在紧张场景下保持基本清晰表达。”

### 4.3 预设自我价值保护规则

- 进入前做三个承诺：
  - 单次评价不得直接晋级为“我是不是笨”“我是不是废物”的结论
  - 结果只能被记录为：当前技能匹配度、准备程度、场景适配度
  - 若情绪过强，只记录事实和感受，延后做重大决策

可以在心里简单说一句：

- “不管发生什么，这只是一次样本，不是关于我整体价值的结论。”

### 4.4 粗略预判能量和风险

- 检查当下状态：
  - 当前能量是否明显偏低？
  - 最近是否已经有很多高压人际事件？
- 若答案为是：
  - 降低当次表现期望：完成基本表达即可
  - 允许自己在紧张中表现得不完美

## 5. 阶段二：场景中

### 5.1 注意力重新分配

- 从“他们怎么评价我？”转向：
  - 我现在要完成的具体任务是什么？
  - 我希望对方带走的 1–2 个关键信息是什么？

### 5.2 简化表达要求

- 给自己一个底线标准：
  - 表达清晰 > 表达完美
  - 让对方理解 > 让对方惊艳
- 对“语言表达不满意”的即时反应：
  - 允许有停顿、重复、语无伦次
  - 不在现场修理自我价值，只专注下一句要说什么

### 5.3 识别典型恐惧触发

常见自动念头：

- “我说错了，他们会觉得我很蠢。”
- “如果表现不好，就没有机会了。”
- “被一群人看见很可怕。”

当识别到这些念头时，只做一个动作：

- 标记为“恐惧驱动的自动念头”，不展开内心辩论
- 把注意力拉回到当前问题、当前句子

### 5.4 对他人的“价值感受”处理

- 对于“对我没明显价值”的人：
  - 保持礼貌、尊重和基本回应
  - 不需要额外讨好，也不需要主动贬低
- 把精力留给：
  - 真正需要投入的关系
  - 本次场景里的关键任务与决策

## 6. 阶段三：结束后 24 小时内

### 6.1 先做简短记录

在 24 小时内，用互动记录模板记录三层内容：

- 感觉层：
  - 当时的主要情绪：紧张 / 害怕 / 羞耻 / 还好 / 兴奋 等
- 事实层：
  - 场景类型、参与人数、我说了什么、对方做了哪些关键反应
- 解释层：
  - 我当前对事件的理解，用“假说”语言描述

暂时不做重大决策（如放弃领域、否定自我能力），应用延时判断原则。

### 6.2 填写自我价值与注意力字段

- 对自我价值的影响：
  - 这次事件整体是强化、削弱还是波动不大
- 能量模式：
  - 事件后能量偏正、持平还是偏负
- 注意力字段：
  - 24 小时内是否反复回想
  - 回想时的主导情绪是什么
  - 是否标记为长期记忆节点

### 6.3 启动自我价值防护流程的条件

若同时满足以下任一组合，可以视为需要额外防护：

- 组合一：
  - 对自我价值的影响：长期偏“削弱”
  - 注意力字段：反复回想为“是”，主导情绪为羞耻或自我厌恶
- 组合二：
  - 单次事件后出现强烈的“我是废物”“我永远不行”类结论
  - 并且持续干扰睡眠或日常任务

此时：

- 优先调用自我系统中的自我价值防护流程
- 暂缓对职业方向、人际总体能力的重大结论

### 6.4 从“失败”翻译为反馈

对于面试、群面、公开表现不理想的情况：

- 把结果翻译为：
  - 当前技能与岗位或场景的匹配度
  - 当前准备程度与要求之间的差距
  - 当前表达、能量管理的实际水平
- 至少写出一条可执行改进点，例如：
  - 下次提前准备 3 个例子
  - 下次在开场前练习 5 分钟呼吸和放松

## 7. 使用节律建议

- 公众场景频次：
  - 在总体能量偏低或连续多次高压后，应主动降低新公众场景的频率
- 复盘频次：
  - 对情绪强烈的公众事件，建议 1–2 次有结构的复盘即可
  - 避免每天重新回放同一事件而不产生新的行动

当系统中积累了一批公众场景记录时，可以定期回顾趋势：

- 哪些场景类型最容易削弱自我价值
- 哪些准备方式显著提高了能量和表现
- 哪些关系或平台需要更强的节律管理或直接降低投入
