# 判断层：人际判断模型字段说明

## 一、感知层字段

- 群体社会伦理标签：职场 / 家人 / 朋友 / 陌生人 / 网络关系 / 其他  
- 行为节奏：快 / 慢 / 混乱 / 机械  
- 情绪基调：紧绷 / 松弛 / 讨好 / 戏谑 / 冷漠  

## 二、动力层字段

- 动力类型：  
  - 恐惧驱动：“我怕……所以动”  
  - 责任驱动：“我必须……所以动”  
  - 渴望驱动：“我想要……所以动”  
  - 使命驱动：“我愿意为了……所以动”  

- 主要追求：被认同 / 权力感 / 安全感 / 掌控感 / 愉悦 / 存在感 / 其他  
- 主要逃避：失败 / 羞辱 / 被忽视 / 被依赖 / 暴露 / 其他  

## 三、结构层字段

- 他赋予我的角色：  
  - 上级 / 下属 / 同伴 / 观众 / 倾诉对象 / 被指责者 / 被拯救者  

- 我习惯扮演的角色：  
  - 讨好者 / 回避者 / 分析者 / 救援者 / 审判者 / 旁观者  

## 四、协议层字段

- 协议等级：  
  - 0：私人闲聊  
  - 1：群体聊天、社群互动  
  - 2：新人引介、商务寒暄  
  - 3：项目对接、会议讨论  
  - 4：面试、演讲、签约  
  - 5：公共发言、正式声明  

- 每个等级对应的：  
  - 期望透明度：可暴露的自我信息程度  
  - 情绪裸露度：可表达的情绪深度  
  - 义务程度：对关系投入的责任强度
