## 人际建模的五层结构（元人际 v1）

面对一个具体的人，本系统通过五个层级来建模对方与关系：

| 层级        | 实际观察维度           | 系统功能              | 自问练习                    |
| --------- | ---------------- | ----------------- | ----------------------- |
| 人际感知层     | 外貌、姿态、穿着、行为节奏    | 构建“他是谁”的初步模型      | 他看起来像哪类人？在发出什么信号？   |
| 人际动力层     | 渴望/恐惧、策略重复、关注点   | 识别其行为背后的驱动力       | 他在追什么？在逃什么？           |
| 人际结构层     | 剧本、角色、结构张力       | 识别当前互动的“关系剧本”     | 他希望我成为谁？我在回应什么剧本？   |
| 人际编码层     | 语言词汇、节奏、情绪波动     | 解读其言语中的操控与目标      | 他没说的是什么？在试图控制什么？    |
| 人际协议层     | 接入机制、互动规则、退出信号   | 主动设计和调整关系的形态与强度 | 这个关系的规则是谁定的？我能调整到几级？ |

这五层共同组成“对他人的工作模型”。任何一次互动，都可以简单问：  
此刻我主要是在用哪一层在看他？有没有遗漏其他层带来的关键信号？

## 预测网络视角：我在做什么

“我”被视为一个社会预测网络，而不是一个被动感受器。

- 识别：当前是哪个模块在运作（如防御性预测、动机判断、结构评估）。
- 校准：这个预测是否有偏差，是否夹杂创伤、投射或误读。
- 决策：是根据这个预测行动，还是暂缓行动、继续收集信息。

“人际建模”的目标不是控制他人，而是在有限样本下，更真实地理解他人和自己，让决策少一点灾难性后果。

## 默认程序与觉察

在没有刻意觉察时，本系统会自动运行一组“默认程序”：

- 力量：快速判断对方相对我的权力位置。
- 吸引：对异性的吸引或排斥反应。
- 归类：他是否属于我熟悉的那类人。
- 价值：他可能带来的资源、机会或威胁。
- 预期：对关系未来走向的二元预测（会变好 / 会变坏）。

这些程序本身并不需要被删除，而是需要被看见。  
一旦察觉到“原来我在按默认程序反应”，就可以减少情绪被它们完全绑架的程度。

## 自我与他人的角色判断

对他人的判断，往往先经过自我判断这一关。

例如：  
“同事会评价我的能量低、能力差”这一想法，本质上首先是我对自己的假设，而不一定是对方的真实想法。  
即使假设它暂时成立，也需要进一步追问：

- 这对现实博弈意味着什么？  
- 在哪些具体场景下，我需要在意这种评价，在哪些场景下可以忽略？
- 我的投入应围绕“收获与负责对象”（如工作成果与直属领导），而不是为了修复所有人的印象。

这样，判断就从“我是不是不行”转向“这对决策有什么影响”。

## 人际协议等级：从非正式到高度正式

“正式 / 非正式”不是二元分类，而是一个连续光谱。  
不同协议等级，对信息透明度、情绪暴露度和责任程度的要求不同。

| 协议等级 | 场景例子             | 应对策略                  |
| ---- | ---------------- | --------------------- |
| 0    | 私人闲聊             | 放松、真实、抒发感受           |
| 1    | 群体聊天、社群互动        | 留意话题调性，不过度主导        |
| 2    | 新人引介、商务寒暄        | 构建基本信任，保持正面与模糊表达    |
| 3    | 项目对接、会议讨论        | 明确结构和目标，主动控节奏        |
| 4    | 面试、演讲、签约         | 精准表达，控制输出，保留边界      |
| 5    | 公共发言、政策呈报、正式声明 | 一字千钧，关注法律和组织责任      |

在任何人际场景中，可以优先判断当前协议等级，再决定：

- 可暴露的信息深度；
- 可投入的情绪和能量强度；
- 应承担的责任范围。

当感到强烈不适或紧张时，也可以先检查：  
是不是我在 L2 的场景里，用了 L0 的暴露方式，或在 L0 的场景里承担了 L4 的紧张程度。
