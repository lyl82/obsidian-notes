## 2. 关键结论与共识

1. 旧原则本质上是“镜像式对等”：完全用他人当下态度来决定自己的态度与行为。
2. 镜像式对等在亲密、功能、弱关系中都会产生问题，无法作为通用人际原则。
3. 真正需要的“对等”，不是情绪对等，而是根据关系类型和时间跨度的“结构性对等”。
4. 面对他人的低评价，需要先做分类：事实能力反馈 / 人格标签 / 情绪投射，分别处理。
5. “结束关系”不是0或1，而是可以拆成：物理结束、角色结束、心理/模式结束多个层级。
6. 降低情绪反应不是终点，更重要的是在情绪可被看见的前提下，保留行为选择权。
7. 在高依赖关系中，简单报复式镜像会主要伤到自己，需要引入“权力/依赖”维度思考。
8. 旧原则背后实际上在防御“被当成傻子、被占便宜”的恐惧，而不是在追求真正的公平。
9. 新方向是：用关系类型、时间、权力结构、自我价值和目标，综合决定每一次具体回应。

## 3. 决策与背后理由

### 决策 1：废止“镜像式对等原则”作为通用人际规则

- 旧原则：  
  【只要你对我好，我会加倍对你好；只要你对我不好，那我也是。】
- 选择：不再把这条原则当作人际互动的默认规则。
- 关键理由：
  - 在亲密关系中，它摧毁修复能力：任何短期情绪波动都会被“加倍”放大。
  - 在功能关系中，它干扰规则执行：对方不专业时的报复式不专业，会反噬自己。
  - 在弱关系中，它让自己频繁被对方拉到同等低水平，不划算。
  - 在高依赖关系中，它变成自损式报复，现实成本主要由自己承担。

### 决策 2：用“关系类型分层 + 五维判断”替代单一对等原则

- 选择：
  - 引入关系类型分层：亲密 / 功能合作 / 弱关系，使用不同期望和规则。
  - 引入五个判断维度：关系类型、时间跨度（单次 vs 模式）、权力/依赖、自我价值、当前目标。
- 关键理由：
  - 不同关系的“合理对等”标准本来就不同，单一规则必然失真。
  - 把情绪、现实利益和长期目标放在一个表里看，能降低被当下情绪劫持的概率。

### 决策 3：将“结束与否”拆成多层，而不是只问“断还是不断”

- 选择：
  - 不再只纠结于“要不要彻底断绝关系”，而是拆解为：
    - 是否需要物理结束（搬离、断联）
    - 是否结束某个角色期待（不再把对方当亲密对象/评审者）
    - 是否结束某种具体模式（如：接受人格标签式评价）
- 关键理由：
  - 现实中存在合租、经济压力、家人身份等约束，立刻物理结束代价太大。
  - 但这不意味着只能“全盘忍耐”，可以先结束/调整具体有害模式。
  - 分层结束能在保留现实互惠的同时，逐步收回自我定义权。

### 决策 4：面对低评价，优先做“类型判断 + 目标选择”，再决定回应方式

- 选择：
  - 先判断：这句话是事实能力反馈、人格标签还是情绪投射。
  - 再判断：这次我优先保护的是自尊感、现实合作，还是未来关系结构。
  - 最后才在“沉默 / 有限理解回应 / 明确边界 / 启动退出”之间做选择。
- 关键理由：
  - 直接镜像式回应（你贬低我，我也贬低你）容易短期爽快、长期失控。
  - 把判断和行动拆开，能让回应更多是“选择”，而不是被情绪驱动的自动反应。

## 6. 对我认知系统的更新建议

> 以下条目建议固化为“原则 / 模板 / 检查清单”的标签

1. **镜像式对等原则-废止**  
   不再用他人当下态度直接决定自己的态度与水平，尤其在高依赖与重要关系中。

2. **关系类型分层模型**  
   按亲密 / 功能合作 / 弱关系分配不同期待和边界，不再用同一套亲密逻辑套所有人。

3. **五维人际判断表**  
   每次关键互动前后，从关系类型、时间跨度、权力/依赖、自我价值、当前目标五个维度做快速评估。

4. **结束的三层结构**  
   把“结束”拆成物理结束、角色结束、心理/模式结束，允许分步降级，而不是非黑即白。

5. **情绪-行为解耦原则**  
   允许自己在被评价时有情绪波动，但不把“有情绪”当作“必须报复”的理由。

6. **低评价三分法**  
   所有低评价先分为：事实能力反馈 / 人格标签 / 情绪投射，能力反馈可采纳，其它部分要么标记、要么设边界。

7. **结构优先于即时爽感**  
   当长期结构（住处、合作、资源）与短期报复快感冲突时，优先保护结构，再找情绪出口。
