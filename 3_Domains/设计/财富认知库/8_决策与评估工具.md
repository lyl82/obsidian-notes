# 模块 8：决策算法 (Decision Algorithms)

## 1. 第一性原理 (First Principles)
本模块基于**概率论**与**行为经济学**。
- **公理**：人脑天生不擅长概率计算，易受情绪（杏仁核）劫持。
- **解决方案**：将决策过程“外包”给冷酷的算法，剥离情绪噪音。
- **核心公式**：$$ E(Decision) = \sum [P_i \times V_i] - Cost_{hidden} $$

## 2. 过滤器链 (Filter Chain Algorithm)

所有决策请求必须依次通过以下 Filter，任何一步 Fail 即终止。

### F1: 物理兼容性检查 (Physical Compatibility)
- **输入**：`Module 0 (Constraints)`
- **算法**：
    ```python
    if new_project.neuro_load > (system.max_load - current_load):
        return REJECT("Overload Risk")
    if new_project.sleep_deprivation_required:
        return REJECT("Bio-Violation")
    ```

### F2: 遍历性检查 (Ergodicity Check)
- **输入**：`Module 5 (Kill Switch)`
- **算法**：
    - 检查是否存在**吸收壁 (Absorbing Barrier)**：即“一旦发生就出局”的风险。
    - 规则：如果 $P(Ruin) > 0$，无论潜在收益多高，一律 REJECT。

### F3: 期望值计算 (Expected Value)
- **输入**：`Module 4 (Assets)`
- **算法**：计算时薪与 ROI。
    - **Base Rate Check**：不要看个例（幸存者），要看基础概率。
    - *Example*：我想做主播。基础概率：99%的主播月入<3000。期望值 = 3000 * 99% + 1000000 * 1% = 2970 + 10000 = 12970? 错！考虑到幸存者偏差，中位数更具参考价值。

### F4: 压力测试 (Stress Test)
- **输入**：`Module 7 (Architecture)`
- **算法**：现金流压力指数 (PI)。
    - $$ PI = \frac{\max(0, FC - RI_{conservative})}{CashBuffer} $$
    - 若 $PI > 0.2$ (即现有资金只能撑5个月)，REJECT 任何非即时变现项目。

## 3. 决策工具箱 (Toolbox)

### 3.1 遗憾最小化框架 (Regret Minimization)
- **场景**：面对两难选择。
- **操作**：想象 80 岁的自己，回看现在。
    - 选 A 失败了会后悔吗？
    - 选 B 错过了会后悔吗？
    - 选择那个“如果不做会更后悔”的选项。

### 3.2 预尸检 (Pre-mortem)
- **场景**：项目启动前。
- **操作**：
    1.  假设现在是 1 年后，项目**彻底失败**了。
    2.  请列出导致失败的所有可能原因。
    3.  针对这些原因，现在制定预防措施。

### 3.3 10-10-10 法则
- **场景**：情绪上头想冲动决策时。
- **操作**：
    - 10 分钟后，我会怎么看这个决定？
    - 10 个月后，我会怎么看？
    - 10 年后，我会怎么看？
    - *通常能瞬间冷却短期情绪。*

## 附：个人宪法层面的理解 (Personal Interpretation)

### 1. 为什么我要把决策权“外包”给算法？
我必须承认，我的大脑是一个被“情绪”和“恐惧”严重污染的处理器。
在压力下，我会因为害怕而拒绝机会（Loss Aversion），或者因为焦虑而抓住救命稻草（Desperation）。这两种模式都曾让我付出惨痛代价。
**我现在不信任“直觉”，我只信任“检查单”。**
当我把一个新的机会输入这套算法时，我就像一个法官在审视别人的案子，而不是当事人。这种抽离感，是我做出正确决策的唯一保障。

### 2. 对“平庸收益”的理性接受
这套算法（特别是 F3 期望值计算）会无情地粉碎一切“暴富幻想”。
它会告诉我：别想了，那个所谓的风口，对你来说概率极低，且风险极高。
接受这个结果是很痛的，因为它意味着我必须老老实实地赚辛苦钱，或者慢慢积累微薄的复利。
**但痛是好事。痛意味着我在接近真实。**
宁可清醒地平庸，也不要梦游着跌落悬崖。

### 3. 拒绝“如果当初...”
有了这套决策系统，我获得了一个巨大的心理红利：**我不再需要为结果负责，我只需要为过程负责。**
如果我严格执行了所有过滤器，最后项目还是失败了，那这就是“系统性风险”或“运气”，而不是“我做错了什么”。
我不需要在深夜里反刍“如果当初我不那么选就好了”。
因为在当时的信息和规则下，那就是**唯一正确的选择**。
这种心理上的免责，对于一个容易自责的人来说，是无价的。
