# 财富认知库设计框架（系统兼容型）

目标：  
构建一套长期可维护的「财富认知库」，用于在**神经系统受限 + 资源稀缺 + 制度不友好**的现实条件下，持续指导个人的生存、收入获取与心理稳定结构设计。

该认知库不是励志系统，而是：

> 面向损伤系统的现实适配型财富操作系统（Wealth OS for constrained runtime）。

---

## 一、总体原则（写入系统顶层 README）

1. 兼容性优先：任何策略必须首先满足神经系统可承受性
    
2. 止损优先于增长：避免长期基线下降高于短期收益
    
3. 多源结构优于单点突破
    
4. 现金流优于净资产幻想
    
5. 心理稳定性属于核心资产，不是副产品
    
6. 默认假设：制度不提供保护性轨道

### 模块 1：财富定义与目标函数（示例）

- 目标重定义
- 生存财富：稳定满足基本生活与医疗恢复的现金流
- 算力财富：持续的可用认知与注意力资源
- 时间/节奏财富：可控且可预测的日程节奏
- 心理安全财富：低威胁/低羞耻输入与可恢复的安全感
- 解释权与结构财富：对自身路径与规则的定义权

- 优先级权重表（初始）

| 目标 | 权重 | 说明 |
|---|---|---|
| 生存财富(S) | 0.35 | 保底现金流优先 |
| 算力财富(C) | 0.20 | 不牺牲长期认知可用性 |
| 时间/节奏(T) | 0.15 | 可中断与节奏稳定 |
| 心理安全(P) | 0.20 | 心理代价受控 |
| 解释权/结构(E) | 0.10 | 避免被动卷入高筛选 |

- 多目标函数（定性）
- F = 0.35·S + 0.20·C + 0.15·T + 0.20·P + 0.10·E
- 在任何决策中，若 P 或 C 下降超过 1 个等级，视为否决条件

### 模块 8：决策与评估工具（示例）

- 兼容性过滤器（通过条件）
- 不触发任一禁区
- 认知负荷 ≤ 设定上限
- 可中断且节奏可控
- 心理代价评估 ≤ 3/5

- 损伤放大过滤器
- 若存在复发模式触发（如熬夜/PK），直接否决

- 可维护性过滤器
- Bus factor = 1 可运行；依赖少；模板化程度高

- 现金流压力测试（简式）
- 固定成本/月 = FC；保守收入/月 = RI；现金缓冲 = CB（月）
- 压力指数 PI = max(0, FC − RI) ÷ CB
- 规则：PI ≤ 500 表示可承受；> 500 需降本或增稳

## 模块详细文档（v1.0）

### 模块 0：系统前提与约束（详细）
- 目的
- 固化不可被乐观叙事覆盖的生理/心理/社会阈值，作为所有决策的硬约束。
- 数据字段
- neuro_state（神经状态摘要）、cog_load_max（日/周可承载认知负荷）、social_capacity（社交承载）、income_vol_threshold（月度波动阈值）、medical_recovery_needs（恢复频率/时长）、no_go_zones[]
- 采集方法
- 每日能量评分（1–5）、任务完成度、社交交互后疲劳评分、睡眠时长、心率或主观焦虑评分
- 阈值设定
- 采用保守法：以过去 4 周平均值的 80% 设定上限；阈值触发即降载
- 维护规则
- 每周审计一次；变更需记录原因与影响；恢复窗口不可挪用

### 模块 1：财富定义与目标函数（详细）
- 目的
- 将“财富”重写为多目标优化，优先保证系统不退化
- 结构
- 目标集合 G = {S, C, T, P, E}；权重 W = {0.35, 0.20, 0.15, 0.20, 0.10}
- 计算（定性到定量）
- 对每一候选路径，分别打分 S/C/T/P/E（0–10），计算 F = Σ Wi·Gi
- 否决条件
- 若 P 或 C 任一下降 2 级以上，直接否决，即使 F 高
- 权重校准
- 每月回顾一次，根据实际风险与压力调整 ±0.05，保持 ΣWi=1
- 输出
- 目标定义表、权重表、否决规则、校准记录

### 模块 4：财富获取方式库（详细）
- 目的
- 收集可行收入方式，按系统兼容性与风险做结构化评估
- 字段模板
- name、entry_barrier、maintenance_cost、system_impact、psych_side_effect、score、cog_load、social_load、stability、interruptibility、income_cap
- 评分方法
- 综合评分 = 0.25·兼容性 + 0.20·稳定性 + 0.20·可中断性 + 0.20·系统影响正向 + 0.15·心理副作用反向
- 风险修正
- 若触发禁区或复发模式，分数上限限定为 6/10
- 管理流程
- 新增 → 试点（小规模）→ 评估 → 合并/下线；每月滚动复盘
- 输出
- 方式条目表、评分器说明、试点记录

### 模块 6：心理稳定结构设计（详细）
