# 判断冻结-初创项目与共创机会

**目的**：把我对「早期初创/共创机会」的直觉判断，升级成可复用的结构化认知与默认决策规则，避免在生存预算紧张时被“有趣项目”带偏。

## 1. 适用范围

- 对象：
  - 处于早期阶段的项目/公司：产品原型已成型，有少量真实用户或测试，但现金流与薪酬结构不明确。
  - 招募方式以「志同道合」「一起做点有意思的事」为主，而非正式 offer。
- 特征：
  - 常见表述：找合伙人 / 核心伙伴 / 共创 / 联合发起人等。
  - 关键信息缺失：工资、股权比例、公司实体、融资情况、工作模式（全职/兼职/远程/时间要求）不清晰。

## 2. 总体冻结结论

- **默认结论**：
  - 这类机会**不用于解决当前生存预算焦虑**，不作为当下的主供能路径。
  - 在我尚未有稳定供能的前提下，只能作为「未来可能的副线/共创样本」，而不是当前主业选择。
- 条件允许时，才把其视为：
  - 有长期回报可能、但短期供能高度不确定的创业/共创路径；
  - 用于满足“价值感、创造力、有趣方向”的补充通道。

## 3. 核心认知维度

### 3.1 生存预算维度

- 现金流：
  - 若无明确薪酬或收入计划，则对当前生存预算模块意味着长期报警。
  - 把这类机会当主业，会在跑道未被拉长的同时，额外消耗时间与注意力。
- 跑道与风险：
  - 初创项目高失败率是结构性事实，而非个人问题。
  - 对我这种低缓冲系统，一次失败可能在心理上被过度归因为“我不行”。

### 3.2 精神基线维度

- 潜在好处：
  - 小团队 + 清晰方向，相比大公司政治噪音更低，压力主要来自产品与进度。
  - 做“让吃饭变有趣”之类有现实价值的产品，内容偏正向。
- 潜在风险：
  - 初创节奏偏快、迭代密度大，“要快”“不断试错”可能与我的算力波动结构冲突。
  - 小团队中个体贡献高度可见，状态波动与掉线容易被放大，并引发强烈自责。
  - 若默认创业文化是“高强度自驱 + 不掉线”，将与我“需要掉线空间”的系统形成结构性冲突。

### 3.3 自尊与角色维度

- 上行空间：
  - 做有现实意义的产品（如健康饮食），可以增强“有意义感”，滋养自尊。
  - 若团队尊重节奏、当我为平等伙伴，自尊感会提升。
- 下行风险：
  - 若对方有高期待（投入/产出速度）而我因状态波动跟不上，易进入“我拖累团队→我不行”的循环。
  - 项目失败时，我倾向将失败过多归因于自己，而非环境与结构。

### 3.4 工作结构维度（节奏/评价/暴露/掉线空间/供能结构）

- 节奏：
  - 要确认每周预期投入小时数、迭代节奏（周/双周/自由）、是否需要大量工作日白天时间。
  - 我的可行节奏需要：有缓冲、允许个别天/周明显掉线，而不会立刻导致结构崩溃。
- 评价机制：
  - 需分清是看“是否稳定在线/随叫随到”，还是看“阶段性产出与作品质量”。
  - 对我友好的结构：以周期性成果为主，而非实时在线状态。
- 暴露度：
  - 内部：小团队高可见度，既是资源也是压力。
  - 外部：是否需要频繁对外 demo、路演、面对投资人/用户？
  - 对我更温和的路径：初期偏向后端/结构/文案/策略等低外显角色，逐步试探自己的承受度。
- 掉线空间：
  - 是否承认“人有波动”，可通过提前交代与分工调整消化我短期算力下降？
  - 是否支持“因健康原因暂时减负/暂停”，而非直接标记为“不靠谱”？
- 供能结构：
  - 需问清是否有收入/融资；加入者是拿工资、股权、还是纯爱好合作。
  - 若答案是“暂无工资，先一起做事看机会”，则仅能作为**兴趣/探索副线**，不能指望它解决短期生存问题。

## 4. 冻结层级与定位

- 在当前阶段：
  - 初创/共创机会统一冻结为「**主线之外的潜在副线选项**」。
  - 主线是：基于雇佣关系的稳定供能岗位。
- 对初创机会的推荐定位：
  - 只有在主供能路径已经基本稳定、且生存预算模块不再高频报警时，才考虑把这类机会提升为“可分配少量时间与精力的共创实验”。

## 5. 白名单：何时可以谨慎靠近这类机会

仅当以下条件大部分满足时，初创机会才进入“可以谨慎接触”的状态：

1. 前提条件
   - 已有基本稳定的收入来源，能够覆盖生活成本。
   - 当前精神基线相对稳定，有余力分出部分算力做尝试。

2. 信息透明度
   - 能够问清：工作模式（全职/兼职、远程/线下）、预期投入时长、薪酬/股权框架、团队结构。
   - 对“状态波动可否被接纳”有明确回答，而不是含糊的鸡汤式鼓励。

3. 角色与边界
   - 自己的角色更偏向“有限责任的协作贡献者”，而非完全背负成功/失败的核心责任。
   - 可以明确定义时间上限与退出机制（例如：先试运行 X 个月，到期一起复盘是否继续）。

若以上条件不成立，则保持当前冻结判断：视为「未来某个可能阶段的样本」，而不是眼前要背上身的选项。

## 6. 操作化：如何使用这条原则

1. 遇到类似“AI + 游戏化 + 健康饮食”这样的初创机会时：
   - 先用本文件评估：在当前阶段，它属于「长期潜力但短期供能不确定」的共创路径。
   - 自动排除其作为“立即解决收入焦虑”的选项。

2. 若仍有兴趣了解：
   - 可按「结构问题清单」提问：节奏、评价机制、暴露度、掉线空间、供能结构等。
   - 将其记录为一个「结构样本」，用于未来在生存稳定后再重新评估。

3. 若未来生存主线稳定后考虑参与：
   - 使用「雇佣工作-判断冻结与复盘.md」记录一次加入前的结构评估与预期。
   - 在实际参与一段时间后，使用复盘区检验三重硬约束是否被满足或突破。

## 7. 更新条件

- 本冻结原则在以下前提下视为有效：
  - 生存预算仍然紧绷，缓冲有限；
  - 精神基线易受高节奏与高暴露影响；
  - 对失败有较强自我归因倾向。
- 仅当以下条件出现时，考虑重新审视该原则：
  - 有了稳定、可持续的主供能岗位；
  - 心理与身体缓冲显著加厚，对波动有更高容忍度；
  - 对失败的归因结构有了明显调整（更能看到结构性因素）。

在那之前，未来的我看到任何“听起来很酷的初创/共创机会”，都可以先翻开本文件，提醒自己：先保住生存与基线，再谈共创与理想。
