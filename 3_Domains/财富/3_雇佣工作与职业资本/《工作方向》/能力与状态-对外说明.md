## 能力与状态说明（对外版）

> 这份说明是给职业顾问 / 潜在合作方看的，目的是让你快速了解：  
> 我现在的能力结构、稳定性边界，以及需要考虑的健康和精力约束。

### 1. 当前状态的整体判断

- 我在有过抑郁和惊恐相关的就医经历，长期存在疲劳、脑雾和睡眠障碍，这影响注意力稳定性和持续工作时长。  从高中时期到当下,目前在管理中。可用能量偏低
    
- 容易过载
    
- 稳定性差
    
- 在节奏失控、突发很多、需要随时响应的环境里，我可以短时间硬撑，但很难长期维持；  
- 在节奏相对可控、目标清楚、以分析和文字 / 文档整理为主的任务中，我的状态明显更稳定，能持续产出。  
- 这些情况和早年的高压用脑、长期熬夜、高刺激依赖（游戏、手机等）以及自我施压有关，目前已经被医生和我自己一起视为**需要长期管理的硬约束**，而不是简单「调整几天就好」的问题。

### 2. 相对稳定的能力与优势

在合适的节奏和任务结构下，我比较稳定的能力主要集中在这几块：

- **结构化整理与写作**  
  - 擅长把零散信息、复杂经历整理成清晰的时间线和结构化说明；  
  - 能用文字把问题讲清楚，适合做说明文档、复盘报告、知识整理等工作。

- **问题分析与抽象**  
  - 习惯从具体事件里抽出「模式」和「结构」，例如区分白名单 / 黑名单岗位结构、总结工作样本的任务负荷和节奏特点；  
  - 对系统性问题（流程、规则、约束）的敏感度较高。

- **基本沟通与协作**  
  - 在精力允许的范围内，可以稳定地和业务方 / 同事沟通需求、确认细节、推进简单项目交付；  
  - 有过项目实施、客户运营、外包验收等一线经验，对实际业务场景有直观认识。

- **自我观察与风险意识**  
  - 能较早识别自己的过载信号（睡眠、脑雾、情绪波动），并据此调整节奏；  
  - 在选择岗位和任务时，会主动考虑长期健康和可持续性，而不是单纯追求短期 output。

### 3. 需要明确的限制与边界

为了避免对彼此都不负责任的期待，有几条边界需要提前说明：

- **连续高强度认知负荷有限**  
  - 难以长时间维持完全清醒、高速的信息处理和复杂决策；  
  - 更适合「中等强度、可拆分的任务块」，而不是全天候高压战斗位。

- **对高随机和高频被动响应敏感**  
  - 客服 / 客户成功 / 7×24 运维这类需要随时接消息、随时切换上下文的岗位，对我来说是高风险结构；  
  - 这类岗位我已经通过真实工作样本验证过，不再考虑重复进入。

- **需要有基本可预期的作息和恢复窗口**  
  - 长期加班、难以保证睡眠的岗位，会很快把状态推回红线；  
  - 理想状态是：工作日内能有至少一些可控的低负荷时间，用于缓冲和恢复。

### 4. 简要的成因交代（只说必要的）

不展开细节，只做必要说明：

- 早年的家庭支持相对有限，长期习惯用「硬扛」来解决问题；  
- 青春期到大学阶段，经历了长期熬夜、高刺激依赖和强烈自我施压，大脑在慢性疲劳和脑雾中运行了很长时间；  
- 工作后，在高压岗位上多次出现持续失眠、惊恐和认知效率明显下降的情况，最终只能通过辞职止损。  

这些经历的结果不是「我什么都做不了」，而是：  
我需要在职业选择和工作设计上，把「精力上限」「节奏可控性」当作一等公民来考虑。

### 5. 目前的工作趋向（供你参考）

综合以上，我目前的工作趋向是：

- 避免高压前线、客服 / 客户成功这类高频被动响应岗位；  
- 更偏向于：
  - 文档类 / 内容整理类 / 基础分析类工作；  
  - 节奏相对稳定、有明确边界的支持类岗位（可以对接人，但不是全天候即时响应）；  
  - 有机会在工作之外保留一部分时间和算力，用于持续恢复和技能沉淀。

如果你在看这份说明时，有任何关于「适合的岗位结构」「能力补全路径」「如何在约束下设计职业发展」的建议，我会非常认真对待。  
这也是我写下这份对外版说明的主要目的：让你基于一个相对真实的状态，来帮我一起做更现实的职业判断。
