## 项目背景：

华为于 2024 年底发布新版本鸿蒙系统，全面剥离 Android 及 Java 兼容层，原有安卓应用与 SDK 无法在新系统运行。为保障平安集团内华为手机用户的业务连续性，部门启动针对 H5、App的CA 认证功能的全面适配与重构工作，建立鸿蒙原生环境下的可靠交付链路。
## 简历叙事-个人职责：

• 文档体系重建：接手时的 PRD 内容主体使用ai自动生成且结构混乱。设计结构化提示模板，将文档语义规范、章节结构和逻辑规则固化为可复用 Prompt，并基于此对全量需求条目进行批量复写与校对，使需求文档在短时间内从不可用状态提升至可交付质量。



• 交付材料库管理与流程加速：在交付材料缺失的情况下重建文档目录体系，将需求、安全、测试类文件推进、分类整理为可直接验收的交付库。由于项目在甲方优先级较低，通过周期性沟通、进度跟进与会议协调，确保验收流程不中断并按节点完成。

•  跨方沟通与信息补全：在缺少背景文档和规范流程的情况下，主动向甲方与研发侧获取所需信息，将碎片化输入整理为明确可执行的收尾路径

• 安全与测试链路协调：协调鸿蒙平台项目的安全架构及研发安全标准自查文档；推动渗透测试与性能测试按时开展；收集系统测试、回归测试、UAT 测试报告，并进行版本号及范围核对，确保正确性与可追溯性。

• 需求对接与交付闭环：主导客户需求沟通与梳理，将业务需求转化为结构化用户故事并落地实施.通过清单化机制推动多角色按时交付，协调研发侧完成需求落地。建立需求条目与交付物（截图等）的逐项映射关系，执行一致性校验；最终确保需求与验收标准对齐.
