# 低压工作指标：{{Title}}

> 用来先把自己的「低压工作」硬指标写清楚，后面在做岗位结构扫描、白名单筛选时，直接对照这张表做排除。

## 1. 收入底线

- **目标底薪**：  
  - 期望底薪：6k 左右  
  - 允许区间：4k–4.5k 可勉强支撑基本生活
- **判断方式**：  
  - 按当前城市的固定支出 + 基本生活开销，估算出每月最低生存预算  
  - 这份工作的稳定到手收入，是否至少覆盖预算，并有少量结余

## 2. 工时与休息结构

- **标准工时**：  
  - 每天：8 小时工作 + 1 小时午休（8+1），大致朝九晚六  
  - 每周：原则上双休，不接受长期单休
- **加班要求**：  
  - 可以接受：偶尔的、提前告知的加班，最好有调休或补偿  
  - 不接受：长期「默认加班」、模糊的「适应加班文化」
- **周结构**：  
  - 默认：双休  
  - 大小周：只有在其他维度非常合适时，才作为例外情况考虑

环境：审美差可以接受，但安全/卫生要达标
## 3. 一句话低压定义（后期填写）

- 对我来说，一份「低压工作」至少要满足：  
  - 收入：  
  - 工时与休息：  
  - 精神与身体负荷：

## 4. 使用说明

- 在填写「岗位结构扫描」或「岗位白名单扫描」时，可以在每个岗位后写一句：  
  - 是否满足当前的低压指标？  
  - 如果不满足，是哪一条越界？
