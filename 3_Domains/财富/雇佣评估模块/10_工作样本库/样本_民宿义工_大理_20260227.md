# 工作样本：民宿义工（大理）

## 1. 基础信息
- **来源**：综合常见xhs招募文案与口碑描述
- **岗位名称**：民宿 义工（以工换宿）
- **工资区间**：通常无固定工资，多为包住 + 可能包部分餐食 + 小额补贴
- **大致工时**：日均约 6–10 小时，节假日与旺季可能更长，排班弹性大但不稳定

## 2. 核心结构印象 (1-5分)
- **环境噪音/混乱度**：4–5（旅游城市民宿，客流与社交活动多，公共区域噪音与打断频繁）
- **身体负荷**：3–4（打扫、铺床、搬运物品与长时间站立，叠加睡眠节奏不稳时消耗放大）
- **节奏紧张度**：4（以客人到店与即时需求为主，旺季和节假日持续处于强实时/弱实时高峰）

## 3. 直觉判断
- **感兴趣程度**：2–3（环境好、城市有吸引力，但岗位本身吸引力一般）暂时逃离原环境
- **初步风险感**：5（服务业前线 + 强实时 + 高噪音 + 情绪劳动 + 低收入）
- **一句话直觉**：对我这种系统来说，更像一项短期高危体验，而不是可行的谋生工作。
