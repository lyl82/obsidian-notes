# 岗位结构扫描：工厂机电维修/进厂维保与装配调试

> 本文以「进厂做设备维修、机电装配与调试」为代表样本，抽象工业现场机电类岗位的共性结构，可复用于：设备维保工程师、驻厂维修、电气装配调试、自动化设备售后驻场等路径的初步结构评估。

## 1. 岗位画像
- **岗位名称**：机电维修/设备维保/装配调试（进厂）
- **典型任务类型**：
  - 维修：故障定位、部件更换、复位与验证、预防性点检
  - 电气：柜内接线、传感器/执行器接线、IO 校验、参数配置
  - 机械：装配定位、对中、链条/皮带/轴承更换、润滑与紧固
  - 调试：单机测试、联动测试、节拍/良率相关调参（视权限与岗位边界）
- **工作组织形态**（常见三类）：
  - 厂内编制（设备部/工程部/自动化部）
  - 外包维保/驻厂（承包商团队）
  - 设备厂家售后/项目调试（短期驻场+验收交付）
- **工资 & 发放方式**：
  - 厂内编制：底薪+补贴/绩效，稳定但上限受体系影响
  - 外包/驻厂：底薪+加班+项目补贴，现金流稳定性中等
  - 项目制/售后：项目补贴与出差补贴显著，但波动与强度更高
- **工时结构**：
  - 常见：两班/三班轮值，或白班+随叫随到
  - 高峰期：设备故障、产线爬坡、验收节点会集中爆发加班

## 3. 三重硬约束判定

### 3.1 生存预算 (Survival)
- **跑道影响**：
  - 厂内/驻厂通常能提供较稳定现金流，对“拉长跑道”有效。
  - 加班与夜班补贴会显著提高收入，但也会提高精神与身体损耗。
- **判断**：
  - 若当前目标是先稳现金流，这类岗位属于“现实可落地”的备选；但要把“夜班与随叫随到”当作主要成本项。

### 3.2 精神基线 (Mental Baseline)
- **损伤预测**：
  - 优势：任务明确、问题驱动、解决即反馈，完成感强，较少“纯社交消耗”。
  - 风险：停线高压与责任归因会诱发持续高警觉；夜班与不规律作息会快速拉低基线。
- **判断**：
  - 若能进入“制度化安全+流程化点检+故障响应有分级”的工厂，精神损伤更可控；若是野蛮管理、随叫随到、长期夜班，则结构性崩溃风险上升。

### 3.3 自尊 (Self-Esteem)
- **自我感知**：
  - 正向面：靠技术把机器救回来，价值感直接且可见。
  - 负向面：停线时容易被当成“救火队”，被催、被归因、被甩锅；外包身份更易被压价与边界侵蚀。
- **判断**：
  - 自尊稳定性取决于“是否有清晰权限边界+是否有事故归责机制+是否能把经验沉淀为专业资产”。

## 4. 结论与决策

**综合合意度**：3（若工厂管理成熟、夜班可控可上调）  
**综合风险度**：4（停线压力与安全风险为主要风险源）

**决策结论（针对当前状态的倾向性判断）**：
- [ ] **不可行** (标记 `#可行性/低`)
- [x] **有风险但可尝试** (标记 `#可行性/中`)
  - *适用场景*：
    - 需要较稳定现金流，且能接受一定强度与噪音环境
    - 更适配“问题驱动+明确交付”的任务形态
  - *优先筛选条件*：
    - 安全体系：LOTO、点检制度、作业许可、事故处置流程
    - 班制：尽量减少长期夜班与随叫随到
    - 现场文化：故障复盘机制而非情绪化归因
    - 学习空间：能接触设备图纸、标准件体系与调试流程
- [ ] **可行/推荐** (标记 `#可行性/高`)

## 5. 试跑验证（1–3天版本）
- 以“观察与跟班”为主：看停线响应流程、谁拍板、谁背锅、是否合规
- 记录三项：当日结束精神状态、当晚睡眠、次日回避/厌恶感
- 重点看两类时段：正常点检窗口 vs 停线救火窗口，差异决定长期可持续性
