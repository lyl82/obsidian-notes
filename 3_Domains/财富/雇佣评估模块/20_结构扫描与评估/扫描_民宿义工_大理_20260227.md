# 岗位结构扫描：民宿义工（大理）

## 1. 岗位画像
- **岗位名称**：民宿 /（以工换宿）
- **公司/店铺类型**：旅游城市小型民宿 / 青旅 / 名宿，老板主导型，小团队运营
- **工资 & 发放方式**：以包住为主，部分提供两餐或小额生活补贴，通常无正式工资与社保，发放与权益约定高度口头化
- **工时结构**：日均约 6–10 小时，淡季略低，旺季与节假日显著上升；早晚班与不规则排班常见，夜间临时需求与加班不可预期

## 3. 三重硬约束判定

### 3.1 生存预算 (Survival)
- **跑道影响**：该岗位主要以住宿与少量伙食折抵开支，缺乏稳定现金收入与社会保障。对拉长整体生存跑道帮助有限，更多是改变支出结构而非建立持续供血。
- **判断**：若目标是谋生与跑道延长，结构上不合格；更接近短期旅居/体验安排，而非可持续工作路径。不提供稳定现金流，只是换一种花钱方式 → 生存预算维度不达标。
现金流角度：
- 义工主要是节省住宿，不产生稳定收入。
- 你需要的不是「住得便宜一点」，而是「在生存预算约束下，建立可持续现金流」。

### 3.2 精神基线 (Mental Baseline)
- **损伤预测**：节奏由客流与老板决定，强实时与弱实时高峰叠加；环境噪音大、打断频繁、情绪劳动持续，对需要稳定节奏与恢复窗口的神经系统构成高压。长期运行大概率从“可恢复的累”演变为慢性过载与崩溃边缘。
- **判断**：对当前阶段的我而言，属于结构性高风险岗位，难以在不牺牲精神基线的前提下长期维持。

### 3.3 自尊 (Self-Esteem)
- **自我感知**：义工身份处于团队底层，法律与制度保护模糊，可替代性极高；评价与指令多由老板与正式员工单向下达，客人的情绪与满意度也会直接折算到个人表现上。
- **判断**：长期处于被替代、被评判的位置，自尊容易被系统性侵蚀；对已对“被当耗材”高度敏感的我来说风险尤大。
