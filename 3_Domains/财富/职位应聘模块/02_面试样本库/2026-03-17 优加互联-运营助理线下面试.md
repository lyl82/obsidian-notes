### 1.1 面试概况（2026-03-17 优加互联·运营助理 线下面试）

- 公司：优加互联（银行服务商，乙方）
- 岗位：运营助理（偏项目执行与活动运营）
- 形式：线下面试
- 主要关注点：项目交付经验、用户沟通与培训、文档撰写能力、对银行业务与SaaS运营的理解、基础数据分析与Excel能力

---

### 1.2 面试问答要点（按话题归类）

**1）项目交付职责与经验**
- 主要职责：需求调研、需求变更沟通、客户培训、文档撰写、上线前后的支持直至验收
- 在深圳法本期间：
  - 建立并整理零散文档体系，形成可交付的文档库
  - 文档类型涵盖：规格书、操作手册、安全测试文档等
  - 使用工具提高效率：文档服务、自动化脚本辅助、数据分析辅助
- 在陕西开放大学“智慧校园”项目：
  - 从项目启动参与：系统安装部署、需求调研、客户培训到重新验收
  - 具备相对完整的软件项目交付闭环经验

**2）自我介绍与职业主线**
- 学历背景：计算机科学与技术本科
- 工作年限：约三年
- 职业主线：B 端软件项目交付与运营、用户运营
- 核心能力：
  - 项目交付经验（需求调研、培训、验收）
  - 客户沟通与系统操作赋能（讲解功能、组织培训）
  - 基础运营支持与问题闭环

**3）从项目交付转向产品运营的原因**
- 希望尝试不同的软件形态与公司运营模式
- 期望更固定、相对稳定的工作环境（相对项目制、短合同）
- 项目交付部分工作成果不错，但公司长期方向与个人发展期待不完全一致
- 因此在阶段性项目结束后选择转向产品运营岗位

**4）工作重心是培训/资质还是交付/运营？**
- 工作经验主要集中在：
  - 软件项目交付和用户支持管理
  - 与客户面对面沟通、教授系统使用、解决疑问和 bug
  - 确保客户需求闭环与项目按时验收
- 在广州米多：
  - 作为 SaaS 运营专员，负责活动配置、客户服务、问题处理
  - 继续承担与客户沟通、系统操作指导等工作

**5）在米多的职责与服务方式**
- 对接约 15 个项目组
- 通过线上（电话等）和线下（现场支持）的方式：
  - 收集客户反馈与需求
  - 根据需求进行系统配置和活动搭建
  - 处理客户疑问与 bug，推动问题闭环
- 核心目标：帮助客户有效利用 SaaS 产品实现营销与业务目标

**6）频繁变动工作的原因**
- 多数项目带有阶段性和短期合作属性：
  - 项目资产验收交付后合作自然结束
  - 部分以短期合同形式存在
- 个人发展方向与公司长期交付导向存在差异
- 在完成阶段性任务后选择离开，寻找更匹配的发展机会

**7）处理用户问题的流程**
- 第一步：结构化判断问题类型
  - 客户操作不当类（使用疑难解答）
  - 系统 bug
  - 新需求或需求理解偏差
- 第二步：结构化定位问题
  - 明确 bug 的具体位置、场景和表现
  - 梳理需求的业务背景和目标
- 第三步：分流处理
  - 需求类：先做基础设计和业务目标梳理，再交给产品部门
  - bug 类：整理复现路径与影响范围，提交技术部门处理

**8）公司产品形态与业务范围**
- 乙方服务商，主要客户为银行（如深圳中行、工行等）
- 两大业务板块：
  - 商城平台运营：
    - 运营自有 SaaS 积分商城
    - 为银行搭建并维护会员/积分商城平台
  - 线上活动营销：
    - 围绕银行业务指标（如信用卡开卡量）设计营销活动
    - 完成方案策划、资源协调、上线执行与效果复盘

**9）线上活动营销的运作流程**
- 根据业务目标（如提升信用卡开卡量）设计活动方案
- 与业务部门沟通确认奖品、预算及活动规则
- 协调内部设计与技术同事落地页面与配置
- 上线活动，监控过程数据与问题
- 活动结束后，输出数据报表，总结活动效果

**10）岗位前三个月的重点能力**
- 学习能力与主动性：
  - 能够快速理解公司的业务模式和银行客户场景
  - 主动追踪任务进度与问题闭环
- 业务理解与上手速度：
  - 快速掌握日常运营支持、商家价/报价流程管理
  - 能准确理解客户需求并转译为内部可执行任务
- 沟通与协同能力：
  - 对内能有效传达客户要求，跟进设计、技术、运营等团队
  - 对外能清晰解释系统功能与活动规则

- 测评环节：
  - 题目一：文字表达能力（文案/说明类）
  - 题目二：工资构成与绩效计算相关的计算题，偏数据分析与 Excel 报表
- 岗位要求：
  - 日常需要处理报表、绩效规则等数据类任务
  - 强调对 Excel 和数据分析的基本掌握
- 自己的当场选择：
  - 觉得绩效工资相关的 Excel 题有挑战性
  - 意识到自己在这类题目和实战数据处理上的准备不足
  - 最终选择直接结束本次面试流程

### 1.4 个人复盘摘要

- 匹配点：
  - 与过往经历高度契合的部分：
    - B 端软件项目交付、客户培训、需求沟通与问题闭环
    - SaaS 产品运营与银行等大客户服务经验
  - 在“执行、沟通、培训、文档”维度有可复用经验
- 短板与风险：
  - 数据报表与 Excel 实战经验偏弱
  - 面临以绩效计算为代表的考题时，心理压力明显，缺少“练过的套路”
- 当前选择的含义：
  - 这次是基于“准备不足 + 短期不愿为该能力付出高成本”的现实性退出
  - 对应的长期问题是：是否补齐基础数据/Excel 能力，或在择岗时主动避开强数据导向岗位
- 后续可行动方向（备忘）：
  - 若未来仍考虑此类岗位：
    - 单独用小项目补一轮“绩效工资/活动数据”类 Excel 能力
  - 若不打算深度做数据：
    - 在筛选岗位时，把对数据/Excel 要求极高的岗位提前排除，主攻更偏项目交付与运营协同的角色
