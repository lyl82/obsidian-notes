先从最底层：人类为什么会有“交易”这个事情？

- 人类世界的核心问题： <br/> 每个人和组织，都要解决两个基本问题： <br/> 1）活下去（有食物、住所、安全）； <br/> 2）最好活得更好（更多资源、更舒适、更有掌控感）。
- “钱”的本质： <br/> 人类发明“钱”，作为一种“通用交换凭证”：
  
  - 你现在提供价值（劳动、产品、服务），
  - 换回“钱”，
  - 以后用“钱”再去换你想要的东西。 <br/> “钱”本身没用，但可以换任何东西，所以大家都追它。
- “市场”的本质： <br/> 很多人想买东西、很多人想卖东西，他们需要一个“相互碰头、出价、成交”的场所，这就是“市场”。
  
  - 线下有菜市场、商场；
  - 线上有电商平台；
  - 在金融里，有“股票市场”、“期货市场”、“外汇市场”等。 <br/> 市场的作用只有一个：
  - 让“谁愿意付更高价格的人”买到东西；
  - 让“谁愿意以更低价格卖的商家”把货卖出去。
- 在金融市场里，“货”是什么？
  
  - 股票：买的是一家公司未来赚到钱的一部分“权利”；
  - 债券：借钱给别人，未来别人还钱加利息；
  - 期货、外汇、加密货币等：本质都是对未来某种东西价格的“猜测”和“博弈”。
