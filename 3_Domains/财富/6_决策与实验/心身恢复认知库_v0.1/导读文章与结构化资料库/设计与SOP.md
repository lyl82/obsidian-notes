# 导读文章与结构化资料库：结构设计与写作SOP

## 目标
- 提供清晰的入口与导航，让用户在3分钟内理解价值

## 内容框架
- 导读文章（项目背景、适用人群、使用方法）
- 总导航索引（六大目录链接）
- 版本说明与更新机制
- FAQ 与用户指引

## 条目规范
- 文件命名：`guide-<主题>.md` / `index.md`
- 元数据：
  ```yaml
  title: "<主题>"
  version: "v0.1"
  status: "draft|published"
  tags: ["导读","导航","更新机制"]
  updated_at: "YYYY-MM-DD"
  ```

## 写作SOP
1. 明确导读核心信息（价值、边界、使用方法）
2. 构建可扫描的总导航索引
3. 标注版本与更新渠道
4. 审阅与术语统一
5. 发布与更新记录
