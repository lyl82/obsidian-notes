# 就医沟通指南：结构设计与写作SOP

## 目标
- 帮助用户更高效地与医生沟通与决策，降低信息不对称

## 内容框架
- 概述与边界
- 门诊准备清单
- 与医生沟通要点
- 复诊与用药调整问答
- 关键话术解释与误解澄清
- 病程记录模板（日志/量表）

## 条目规范
- 文件命名：`comm-<主题>.md`
- 元数据：
  ```yaml
  title: "<主题>"
  version: "v0.1"
  status: "draft|published"
  tags: ["就医沟通","清单"]
  updated_at: "YYYY-MM-DD"
  ```

## 写作SOP
1. 明确场景与目标（初诊/复诊/换药）
2. 提炼清单与要点（可打印/可复用）
3. 澄清常见话术与误解
4. 校对与术语统一
5. 发布与更新记录
