# 心身恢复认知库 v0.1

## 目标与范围
- 面向正在经历抑郁/焦虑/躯体化并已就医或准备就医的用户
- 提供病程、症状、药物、就医沟通与真实案例的最低可用认知模型
- 不提供诊断、替代医疗建议或保证治愈

## 目录结构
- 病程阶段地图：阶段定义、过渡机制、常见误解与可视化地图
- 常见症状与反应解释：症状条目模板与误解澄清
- 药物认知与风险说明：药物基础、反应处理、禁忌与沟通要点
- 就医沟通指南：门诊准备、复诊策略、关键话术解释
- 真实恢复案例拆解：结构化案例模板与复盘规范
- 导读文章与结构化资料库：总导航、版本说明、FAQ与更新机制

## 写作与更新原则
- 版本化维护（v0.1 起），每次更新记录更新日志
- 所有条目遵循统一的元数据与命名规范
- 优先围绕用户的真实高频问题迭代

## 版本约定
- 初始版本：v0.1（MVP）
- 迭代记录在“导读文章与结构化资料库”目录的更新日志中
