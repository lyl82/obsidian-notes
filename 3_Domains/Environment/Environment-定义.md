# LifeOS · Environment 环境对象 · 定义卷

# 对象

本卷定义「Environment 环境对象」在 LifeOS 中的角色、边界和成功标准，写给未来的自己，用来在犹豫时有一个可以依托的结构性判断基准。

Environment 在此不等于「家的感觉」或「装饰审美」，而是指：支撑我这个系统安全、稳定、低熵运行的物理与组织性环境基础设施层。

## 一、总则

- Environment 是 LifeOS 的基础设施层之一，负责维护「容器（Container）/ 资源（Resource）/ 垃圾与熵（Entropy）」的秩序，使其他领域 Service 可以在可预期、可恢复的物理环境中运行。
- 本对象优先保障：水、食物、可睡眠空间、基本安全、行动路径清晰，以及「不因为基础事务打断高价值状态」。美观与仪式感可以是附加收益，但不作为首要目标。
- Environment 不依赖「心情」与「自我评价」来启动，而接受来自系统态（日型、能量状态、睡眠窗口）的调度信号。情绪可以影响执行强度，但不能否定最低维护动作。
- Environment 的所有条款，可以在真实生活数据（DAO）与长期体验的基础上被修订，但必须保留旧版本的痕迹，视为系统演化而非当场推翻。

## 二、对象范围

- 包含：
  - 居住空间：房间、床、地面、通道。
  - 工作空间：桌面、椅子、电脑周边。
  - 储存与携带：冰箱、储物柜、背包、常用抽屉。
  - 身体作为容器：基础清洁、可睡眠性、衣物穿着的基本舒适度。
  - 与上述容器直接相关的资源与熵：饮用水、可即食食物、干净衣物、干净餐具、垃圾、灰尘、油污、包装物、过期物品等。
- 暂不包含：
  - 审美性装饰（如摆件、墙面风格），除非直接影响使用与安全。
  - 大型装修、搬家等一次性工程，这些可以在未来单独建立项目对象。

## 三、核心目的

- 在绝大多数时间内，确保：
  - 任意时刻 5 分钟内可以获得：一杯水、一份可吃的食物、一块可直接躺下的睡眠空间。
  - 高价值状态（思考、深度工作、外出、深度休息）不被基础事务频繁打断。
  - 单点失败（某个容器或工具出问题）不会快速演变为连锁灾难（大面积不可用、彻夜收拾、临时崩溃）。
- 减少「注意力被垃圾牵走」的情况，使环境维护尽可能被流程化、机械化，而不是依赖瞬时的意志力与羞耻感。
- 将环境维护视为「生命支持系统（Life Support）」的一部分：不是自律表演，而是为能量、睡眠、认知提供稳定运行时。

## 四、工作假设

- 熵的积累是持续的、与心情无关的：不因为我开心或难过，灰尘和垃圾就停止生成。因此，Environment 必须预设固定的释放机制，而不能完全依赖心情驱动的大扫除。
- 绝大多数「崩溃日」体验，并非只由心理问题导致，而是由：睡眠/能量问题 + 环境失控（乱、脏、找不到东西）共同放大。因此，单独修心理而忽略环境，是不完整的。
- 环境的「最小可用状态（Minimal Viable State, MVS）」往往远低于完美整洁：床能睡、桌能放电脑、水能喝、路能走，这些已经足以显著降低系统风险。在此基础上的美化，是加分项而非刚需。
- Environment 与节律紧密耦合：每天 22:00 之后的收尾窗口，是环境系统的主要运行时段之一；白天只允许小步维护，而不鼓励占用黄金算力做大规模整理。

## 五、成功的定义

当以下大部分条件被长期满足时，可以认为当前 Environment 对象处于「暂时成功的版本」：

- 绝大多数日子里，我不会因为：找不到东西、没水喝、没有可吃的东西、床上乱到无法躺下，而被迫中断当天的计划。
- 工作 / 学习 / 外出前后的准备与收尾，变成一套可重复的小流程，而不是每次都临时应对、慌乱找物品。
- 房间与桌面可以在 10–20 分钟内，从任何日常使用状态恢复到「最小可用状态」，而不需要一整天的大扫除。
- 情绪低落或能量低时，依然可以通过执行极少的最低维护动作，使环境保持「可以活下去 / 可以睡觉 / 可以补给」的基线，而不是彻底放弃。
- 对「打扫 / 整理」的感受，从纯粹的自责与拖延，转变为一种带有安全感的维护行为：在做这些事时，是在确保明天的自己更安全，而不是在惩罚今天的自己。

## 六、与其他对象的关系

- 与 SERVICE-E（能量第一性）的关系：
  - Environment 提供水、食物、可睡眠空间、光线基础等硬条件，使能量系统有安放之处。
  - 当能量严重透支或日型降级为「崩溃日」时，Environment 必须自动切换到最低动作集，绝不抢占睡眠和恢复。
- 与 System State「睡眠」的关系：
  - 睡眠是全局互斥锁；Environment 在睡前窗口承担「环境降速与收尾」的职责，为睡眠创造足够安全、干净、可躺的物理边界。
  - 若环境状态严重干扰睡眠（床不可睡、噪音、光污染），视为 Environment 领域的重大故障，必须在 DAO 中记录并用于修订本定义与控制规则。
- 与 Health/Work/Relationships 等对象的关系：
  - Health：环境决定很多健康行为是否易于发生（例如清水易取、运动空间有无）。
  - Work：桌面与数字环境的秩序，直接影响深度工作是否容易进入与维持。
  - Relationships：居住环境的秩序，会影响邀请他人到访时的心理压力与自我评价。

## 七、修订机制

- 若在真实生活中反复出现以下情况之一，即视为需要审查与修订本定义卷：
  - 连续数周，因为缺水、缺食物、床面不可睡、找不到关键物品，而多次中断工作或计划。
  - 夜间入睡或夜间醒来时，环境带来的不适（凌乱、脏乱差、气味）明显放大了焦虑或崩溃体验。
  - 环境维护本身变成一种高压力任务，使我频繁为了追求「完美整洁」而牺牲睡眠和能量。
- 修订动机可以来自崩溃日的复盘，也可以来自稳定期的优化思考，但不允许在一时冲动或极端情绪状态下，直接推翻核心条款。
- 本定义卷的目标是提供一个稳定的解释框架，而不是把生活锁死在某个版本；因此，允许版本演进，前提是每次修订后，都能说清：新的条款如何更好地服务于能量第一性与系统稳定性。
