# 人际判断系统宪法 v0.1（Relationships Constitution）

## 第一章：系统的定义与边界

1. 本系统服务的对象，是“我与他人的实际互动”，而不是抽象的人性讨论。  
2. 本系统的产品，不是“更讨人喜欢”，而是“在有限硬件条件下，做更少灾难性的人际判断和决策”。  
3. 本系统只负责三件事：  
   - 识别：在具体场景中，正在发生的是什么类型的人际结构；  
   - 评估：这段关系在风险、消耗与价值上的大致区间；  
   - 决策：对投入程度、边界和退出策略给出可执行的建议。  
4. 本系统不负责：  
   - 治愈他人、修复他人的人格或创伤；  
   - 保证任何关系一定“走向美好”；  
   - 把现实世界变成理想剧本。  

## 第二章：关于“我”与“他人”的基本假设

1. “我”是一个受神经硬件限制的预测系统，带着长期疲劳与防御负荷运行，任何感受与记忆都不完整。  
2. “他人”同样是有限的系统，有自己的动力、盲点、防御与历史，并不以我的需求为设计中心。  
3. 没有人是“唯一的真相所有者”，所有人都在用各自的有限模型解释世界。  
4. 任何单次互动中看到的“他”，只是他在特定状态、特定场域下的一个截面，而不是完整的人。  
5. 以上假设一旦被遗忘，本系统的所有判断默认失效，需重新审查。  

## 第三章：关于“关系”的功能定位

1. 人际关系首先是一种“资源与信息流动的结构”，包括：  
   - 情感资源：支持、陪伴、理解、认同；  
   - 物质与机会资源：金钱、合作、信息与机会；  
   - 结构性资源：角色、身份、归属感。  
2. 任何关系同时携带：价值、成本与风险，三者必须一起评估。  
3. 本系统不得只因为某段关系“很重要”或“很特别”，就忽略成本与风险的评估。  
4. 关系不是用来证明自我价值的道具，而是与生活其他部分一样，需要被纳入整体资源管理。  

## 第四章：关于“判断”的本体论

1. 对人的判断，是在有限样本与偏倚感知下构建的“工作模型”，本质上是工具，而不是真理。  
2. 模型的合法用途是：  
   - 帮助我提前预估某人某种场景下的大致反应区间；  
   - 帮助我决定在这段关系中投入多少时间、情感和风险敞口；  
   - 帮助我选择适合的沟通方式与边界设置。  
3. 模型的非法用途包括：  
   - 把早期判断当作对整个人的终身定性；  
   - 用“模型”替代对方的主观经验与自我陈述；  
   - 以“我看透你”为名，切断对现实反馈的继续观察。  
4. 若模型与现实长期冲突，本系统应优先质疑模型，而非急于给对方或自己贴上新的负面标签。  

## 第五章：基本认知原则

1. 有限性原则  
   - 所有感知、记忆与解释都带有噪音与缺失，本系统不得假设“我已经看到全部真相”。  
2. 对称人性原则  
   - 允许他人同时具有真实的痛苦与不成熟的行为模式，既不是纯恶，也不是纯善。  
   - 本系统应尽量同时看到对方的动力与局限，而不是单一化为“好人/坏人”。  
3. 多因性原则  
   - 任何关系中的问题，优先被视作多重因素叠加的结果，而不是单一“谁的错”。  
   - 在归因之前，本系统应区分：结构问题、边界问题、能力问题与价值观冲突。  
4. 不读心原则  
   - 本系统不能直接访问他人的内心世界，只能基于稳定行为模式与明示信息做有限推断。  
   - 对于无法验证的动机猜测，一律标记为“假说”，不得当作事实使用。  
5. 复杂度保护原则  
   - 每个人都可以同时在不同关系中扮演不同角色，本系统不得用单一标签覆盖一个人的全部维度。  

## 第六章：操作与安全原则

1. 分层记录原则  
   - 本系统在记录任何人际事件时，应尽量区分四个层次：  
     - 感觉层：我当时的情绪与身体感受；  
     - 事实层：可具体描述的行为与事件；  
     - 解释层：我对这些行为的推断与模型；  
     - 决策层：基于当前模型做出的下一步行动选择。  
   - 任何后续复盘，应允许修改“解释层”和“决策层”，而不篡改当时的“感觉层”与“事实层”记录。  
2. 延时判断原则  
   - 在情绪强度极高、能量明显枯竭时，本系统只记录，不裁决。  
   - 重要的人际决策（彻底断联、表白、合作或终止合作等），应在至少一次睡眠之后再确认。  
3. 渐进更新原则  
   - 对重要人物和重要关系的模型更新，应尽量采用小步修正，而非频繁的剧烈翻转。  
   - 若需要做“根本性翻转”，必须有足够多、足够重的新证据支持。  
4. 未知保留原则  
   - 对信息明显不足的对象或维度，本系统可以长期维持“未判断”状态。  
   - “暂不判断”是一种主动决策，而不是懒惰或失败。  
5. 防破产优先原则  
   - 在价值与风险出现冲突时，本系统先保护整体生活系统的生存与稳定，再考虑理想化的人际追求。  
   - 对于明显超出自身承载能力的关系需求，本系统有权直接降低投入或退出。  

## 第七章：错误与复原

1. 本系统默认：在复杂人际环境中，犯错是常态，零错误是不现实的目标。  
2. 宪法级目标不是“永不误判”，而是“尽量减少不可逆的大错，并快速从小错中学习”。  
3. 当出现以下信号时，应自动触发“暂停重大人际决策”的安全程序：  
   - 极端理想化或极端妖魔化某个人；  
   - 强烈的羞耻、自我厌恶或被彻底否定感；  
   - 长时间反复回放同一场景却得出完全相反的结论。  
4. 复原流程包括：  
   - 回到事实层重建事件描述；  
   - 检查当前模型用了哪些未被验证的假设；  
   - 在必要时，寻求外部视角帮助校正。  

## 第八章：与整个 LifeOS 的关系

1. 人际判断系统是整个 LifeOS 的一个子系统，必须服从更高层的神经、任务与价值公理。  
2. 当人际判断与身体健康、长期任务或核心价值发生冲突时，应由 LifeOS 总体规则仲裁，而不是由短期人际情绪主导。  
3. 本宪法只规定“如何对人和关系做判断”，不规定“人生应该以什么为最终目的”。  
4. 若未来 LifeOS 内核发生重大升级，本宪法需根据新内核进行相应修订。
