# 意识刺激四大源

## 内在源（Self / 内在涌现）
- 自发冒出的念头、灵感
- 对某件事的看法、总结、顿悟
- 情绪波动背后的自言自语
  - 例：「我又觉得自己不行了」
  - 例：「这次有戏」
- 特征：无外部明显刺激，脑内自产
- 记录载体：飞书云表格
## 他人源（People / 关系触发）
- 一次对话、争执、安慰
- 被评价、否定、赞美后的想法
- 对具体人的投射
  - 羡慕
  - 嫉妒
  - 厌恶
  - 想模仿
- 特征：因具体人/关系才冒出意识

## 信息源（Info / 智能信息生态系统）
- 社交媒体信息流
  - X
  - 小红书
  - B 站
  - 公众号
  - 播客
- 书籍 / 文章 / 课程 / 视频
- 工具/系统提示
  - 智能助手
  - 推荐算法
- 本质：人工组织的符号/内容对大脑形成刺激

## 环境基线（Environment / 场域）
- 地点
- 身体状态
  - 困
  - 兴奋
  - 生病
- 时间压力
- 噪音
- 作用：非内容因子，但会显著改变前三类输出形态
  - 例：地铁挤 v.s. 书桌安静 → 同样刷社媒体感完全不同
