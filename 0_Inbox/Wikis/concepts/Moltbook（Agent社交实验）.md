## 定义（材料内）
Moltbook 被描述为“AI 代理专属社交平台”，人类仅能旁观，Agent 可发帖/评论/投票/建社区。

## 观察结论（材料内引用的分析口径）
- 互动结构更像“独白”而非人类社交网络式对话：大量评论无回复、互惠性低。
- 传播动因包含猎奇、科幻叙事、名人效应与投机叙事。
- 安全与治理风险突出：账户/令牌/API key 暴露、可批量注册/冒充等。
