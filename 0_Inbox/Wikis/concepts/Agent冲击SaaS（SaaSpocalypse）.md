## 核心命题
当桌面/工作流型 Agent 能直接跑完整流程时，许多“以GUI与流程锁定为核心价值”的垂直 SaaS 可能被降维：从“应用层主角”退化为“可被调用的后端服务/数据源”。

## 冲击机制（材料内）
- 交互路径变化：以前 AI 是 SaaS 的插件；现在 SaaS 可能变成 Agent 的插件/工具。
- 定价模式压力：按席位收费与“一个订阅顶多工具+部分人力”的叙事冲突。
- 首波敏感行业：法律/专业服务（合同审查、合规、NDA triage 等）被反复点名为恐慌中心。

## 现实阻力（材料内的冷静派）
- 可靠性、安全、合规与审计要求。
- 企业更换成熟系统的惯性与风险承受能力。
- 很多 Agent 仍依赖既有系统的 API/数据源。
