## 核心内容
围绕 Anthropic 推出 Claude Cowork 与一组 starter plugins 引发的“SaaSpocalypse”叙事：时间线、市场恐惧点、社交媒体主流认知结构与分歧。

## 关键点（原文叙事）
- Cowork 被描述为“能在电脑上像同事一样工作”的 agent 工具；插件覆盖多个部门场景。
- 市场恐惧集中在：从“助手”转为“替代者”、席位订阅被颠覆、迭代速度碾压、法律领域冲击最大。
- 社媒观点两极：末日恐慌为主，也有“可靠性/合规仍待验证”的冷静派。
