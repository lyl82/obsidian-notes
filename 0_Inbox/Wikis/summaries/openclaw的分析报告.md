## 核心内容
对 OpenClaw 的项目概述、分层架构、使用场景、风险与“为什么会火”的解释；并与 AI 编辑器（IDE内协作）做差异对比，强调“手机下达命令、后台异步执行、推送验收”的科幻式体验。

## 关键点（原文叙事）
- OpenClaw：本地/自托管、IM作为界面、技能生态、长期运行。
- 安全争议：高权限 + prompt injection + skill 供应链风险。
- 热门原因：从聊天到行动的时代心理、低门槛高“哇塞感”、社区扩散与争议放大。
