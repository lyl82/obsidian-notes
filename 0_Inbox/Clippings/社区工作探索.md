## 社区两委是什么

**社区两委** 就是： **社区党支部委员会 + 社区居民委员会** ，基层最核心的两个管理组织，简称 **村 / 社区两委** （村里叫村两委，城里叫社区两委）。

## 一、分别是什么

1. **社区党支部（党委 / 党总支）**
- 是 **党组织** ，领导核心
- 管方向、管干部、抓党建、重大事项把关
2. **社区居民委员会**
- 是 **居民自治组织** ，民间自治机构
- 办民生实事：物业协调、低保、养老、计生、邻里矛盾、社区服务、环境卫生等

## 二、简单一句话

**党支部是领导，居委会是办事干活的** ，两个班子合起来就叫 **社区两委** 。

## 三、常见特点

- 很多地方 **两委干部交叉任职** ，一人兼两个职务
- 是街道、乡镇下面最基层的治理单元
- 网格员、社区工作者都归两委统筹管理

## 一、社区工作都有哪些岗位？（先分清）

1. **社区 “两委” 干部** （支部委员、居委会委员）
	- 选举产生，有编制 / 事业编倾向，稳定、晋升空间大。
2. **社区专职工作者（社工）**
	- 统一招考，合同聘用（2–5 年一签），最常见，含 **网格员、民政、计生、党建、综治** 等岗位。
3. **公益性岗位 / 见习岗**
	- 门槛低、工资低，过渡用，不算正式社工。

我们一般说 “找社区工作”，主要指 **社区专职工作者（含网格员）** 。

---

## 二、报考条件（全国通用，各地微调）

1. **年龄** ：18–40 岁为主，部分地区女≤45、男≤50。
2. **学历** ： **大专及以上** ，专业不限；少数地方退伍军人可放宽到高中。
3. **户籍** ：多数要 **本市 / 本区户籍** ；有 \*\* 社工证（助理社工师 / 社工师）\*\* 常不限户籍船山区人民政府。
4. **政治** ：拥护党、无犯罪、无失信、品行端正。
5. **加分项（很重要）**
	- 中共党员、退役军人、有社工证、基层服务项目期满（三支一扶等）。

## 三、去哪找招聘信息（最权威渠道）

1. **官方网站（必看）**
	- 市 / 区 **人民政府官网** → 政务公开 / 通知公告
		- 市 / 区 **民政局、人社局、党建网**
2. **公众号**
	- 本地：“XX 市 / 区 社区工作者招聘”“XX 民政”“XX 党建”
3. **考试时间**
	- 集中在 **每年 3–6 月、9–11 月** ，一年 1–2 次统考。

## 四、招聘流程（一步不差）

公告 → 网上报名 → 初审 → 笔试 → 资格复审 → 面试 → 体检 → 政审 → 公示 → 聘用（签合同）

## 五、考试考什么（小白重点）

### 笔试（常见 3 科）

1. **公共基础知识（公基）** ：政治、法律（民法典、居委会组织法）、公文、时政、经济、人文。
2. **社区专业知识（社专）** ：社区概论、社区建设、居民自治、社会工作实务、网格员职责。
3. **行测 / 写作** ：言语、判断、资料分析；或公文写作（通知、纪要、倡议书）。

### 面试（结构化为主）

- 题型： **自我认知、应急应变、人际关系、综合分析、组织活动** 。
- 例子：居民投诉物业，你怎么处理？组织一次社区敬老活动，你怎么做？

---

## 六、日常工作内容（真实情况）

一句话： **上管天、下管地、中间管空气，居民大小事都找你** 。

- 党建：党员管理、主题党日、宣传
- 民生：低保、养老、医保、残疾人、计生
- 网格：巡查、隐患上报、矛盾调解、民情收集
- 文明：卫生、垃圾分类、创文创卫
- 综治：反诈、维稳、特殊人群管理
- 活动：节日活动、志愿服务、邻里节

特点： **事杂、琐碎、接地气、要耐心、沟通多** 。

## 七、待遇与前景（实话实说）

### 待遇（2026 年，三四线 / 县城参考）

- 月薪： **3500–6000 元** （含五险一金）
- 五险一金齐全，部分有年终奖、节日福利
- 发达地区（一线 / 新一线）： **6000–10000+**

### 前景

- 稳定：合同制，基本不裁员，适合求稳
- 晋升：社工 → 副网格长 / 副主任 → 网格长 / 主任 → 街道事业编 / 公务员（有渠道）
- 考证： **助理社工师→社工师→高级社工师** ，加薪 + 加分 + 转编优势。

1. 先查自己 **户籍 + 学历 + 年龄** 是否符合。

- ❌ 工作轻松： **事多、琐碎、加班常有，但压力比企业小** 。

市场化的「上升性」，本质是 **用精力、健康、情绪、时间换成长和薪资上限** 。但对你的硬件条件来说： **兑换成本太高，性价比极低** 。

## 三、进入流程（以社区 / 网格员为例，最简单、最清晰）

## 四、你最关心：真实消耗（帮你对标自己的承受力）

我按「 **精力消耗、情绪消耗、人际消耗、加班频率** 」给你打分（1–5，5 最高）：

### ✅ 最匹配你（低消耗、低社交、规律）

- **机关编外文员 / 档案** ：精力 2、情绪 2、人际 2、加班 1（极少加班）
- **图书馆 / 文化馆辅助岗** ：精力 2、情绪 1、人际 1、加班 1（最轻松一档）

### ⚠️ 中等消耗（可接受，但有内耗）

- **政务窗口** ：精力 3、情绪 4（投诉多）、人际 3、加班 1
- **国企行政 / 党务** ：精力 3、情绪 2、人际 3、加班 2（偶尔加班）

- **社区书记 / 两委** ：精力 5、情绪 5、人际 5、加班 5（高强度、责任大）

一句话总结： **网格员、社区社工、机关文员、图书馆岗，大概率在你承受范围内** ；它们的消耗是「琐碎、重复、台账」，不是市场化那种「高压、突发、熬夜、出差」。
