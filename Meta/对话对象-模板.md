# 对话对象模板（单次对话标准结构）

> 用于记录「我与 AI 围绕某个具体对象展开的一次对话」。  
> 建议：每当一轮对话的重要性 ≥「值得以后回看」，就创建一份这样的记录。

## 0. 元信息

- 对话标题：{{title}}
- 日期：{{date}}
- 相关主要对象：
  - [[关联对象1]]
  - [[关联对象2]]
- 关联项目/领域（可选）：
  - [[关联项目或领域]]

## 1. 本次核心问题

- 一句话描述：
  - 我想搞清楚 / 解决的核心问题是：……
- 关键背景：
  - 已知条件 / 约束 / 历史决定：……
  - 关键链接：
    - [[相关最高解释文件]]
    - [[相关项目文档]]

## 2. 对话摘要（由结果回填）

- 主要讨论路径：
  - A → B → C 的推理/探索路线
- 关键结论：
  - 结论 1：……
  - 结论 2：……
- 重要前提/假设：
  - 假设 1：……
  - 假设 2：……

## 3. 决策与行动

- 立即执行的行动（Next Actions）：
  - [ ] 行动 1（链接到相关对象或项目）
  - [ ] 行动 2
- 需要更新/创建的对象文件：
  - [[对象文件1]]：需要写入/修改的内容要点
  - [[对象文件2]]：……

## 4. 对系统本身的反馈（Meta）

- 本次对话，对「认知对话系统」有什么启发？
  - 例如：
    - 发现需要一种新的对象类型 / 模板
    - 发现当前文件结构不够匹配思维流
- 如有必要，请在：
  - [[认知对话系统-最高解释文件]] 或
  - `LifeOS_AI_Context.md`
  中，记录对应的结构性调整。

## 5. 原始记录（可选）

- 这里可以：
  - 粘贴关键对话片段
  - 记录本地/外部日志的引用
  - 或简单写一句：「详细原始记录见：……」
