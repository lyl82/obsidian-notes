# 12. 未来迭代方向

## 12.1 阶段一：手动闭环 (Current)
- **重点**：跑通“流 -> 库”的流程，建立习惯。
- **工具**：飞书表格 + Claude/GPT + Obsidian (手动复制粘贴)。

## 12.2 阶段二：半自动化 (Semi-Automation)
- **重点**：降低“搬运”成本。
- **功能**：
    - **自动抓取脚本**：编写 Python 脚本，每天自动从飞书 API 拉取 Log，存为 Obsidian 中的 Daily Note。
    - **模板生成器**：通过 QuickAdd 等插件，一键生成“对象最高解释文件”骨架。

## 12.3 阶段三：本地 RAG (Local Intelligence)
- **重点**：让 AI 拥有全量记忆。
- **功能**：
    - **向量数据库**：将 Obsidian 库向量化，实现语义搜索。
    - **本地模型**：在本地运行小参数模型（如 Llama 3 8B），保护隐私且无延迟。

## 12.4 阶段四：多智能体协作 (Multi-Agent Swarm)
- **重点**：专业分工。
- **架构**：
    - **Health Agent**：专盯健康数据和睡眠。
    - **Finance Agent**：专盯预算和支出。
    - **Master Agent**：协调各分身，向用户汇报。
