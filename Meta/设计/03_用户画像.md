# 03. 用户画像（你）

## 3.1 基础属性
- **角色**：高认知负荷的知识工作者 / 终身学习者。
- **特质**：
    - **高信息摄入 (High Input)**：日常接触大量异构信息，需要高效的过滤与吸收机制。
    - **深度反思 (Reflective)**：习惯于对自身行为和思维模式进行元认知（Meta-Cognition）层面的审视。
    - **系统化思维 (Systematic)**：倾向于用结构、模型和流程来解决问题，而非依赖随机灵感。

## 3.2 痛点与需求

### 3.2.1 对“一致性”的极度敏感
- **痛点**：厌恶“昨天觉得A对，今天觉得B对”的随机性，除非有充分的新证据。
- **需求**：需要一个“外部锚点”来锁定共识。文件系统就是这个锚点。

### 3.2.2 对“重复犯错”的零容忍
- **痛点**：同一个坑踩两次会带来巨大的挫败感和自我怀疑。
- **需求**：必须有“错误数据库”和“预警机制”，在类似情境再次出现时自动触发（IF-THEN 规则）。

### 3.2.3 能量瓶颈 (Energy Constraint)
- **痛点**：认知能力受生理能量（血糖、睡眠、压力）影响巨大。
- **需求**：系统设计必须遵循 **SERVICE-E (Energy First)** 原则。
    - 在高能量时：进行系统重构、深度思考、规则制定（Write Mode）。
    - 在低能量时：仅执行既定 SOP、查阅文档、做简单记录（Read/Execute Mode）。

## 3.3 交互偏好
- **文本优先**：偏好 Markdown、表格、结构化文本。
- **控制欲**：偏好本地存储（Local First），掌握数据所有权，不依赖黑盒 SaaS。
- **异步协作**：与 AI 的交互更像是由用户发起工单（Prompt），AI 完成后提交交付物（Response），用户审核入库。
