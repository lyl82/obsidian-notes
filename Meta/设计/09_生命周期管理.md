# 09. 生命周期管理

## 9.1 对象生命周期 (Object Lifecycle)

LifeOS 中的每个对象都应处于以下状态之一，严禁出现“僵尸对象”。

### 1. Incubating (孵化中/草稿)
- **定义**：一个模糊的想法，尚未完全成型。
- **位置**：`0_Inbox` 或 `Meta/temp.md`。
- **动作**：允许随意修改，无需严格结构。

### 2. Active (活跃/运行中)
- **定义**：当前正在投入资源、关注或维护的对象。
- **位置**：`3_Domains` 或 `4_Projects` 的正式目录。
- **要求**：必须有“最高解释文件”，必须有明确的 Next Actions。

### 3. Frozen (冻结/暂停)
- **定义**：暂时不投入资源，但未来可能会恢复的对象。
- **位置**：保留在原位，但 Status 标记为 `Frozen`。
- **规则**：不应出现在日常的 Todo 列表或 Review 视图中。

### 4. Archived (归档/完成)
- **定义**：已结束或不再需要的对象。
- **位置**：移动到 `7_Archive`。
- **意义**：作为历史参考，不再维护。

## 9.2 垃圾回收机制 (Garbage Collection)

为了防止系统臃肿（Entropy），需要定期 GC。

- **触发条件**：每月一次，或当磁盘/认知负载过重时。
- **操作**：
    1.  扫描所有 `Active` 对象。
    2.  检查 `Last_updated` 时间。
    3.  如果 > 3个月未更新：
        - 询问："这个对象还重要吗？"
        - 若否 -> 移动到 `7_Archive`。
        - 若是 -> 降级为 `Frozen` 或 立即执行一次维护。
