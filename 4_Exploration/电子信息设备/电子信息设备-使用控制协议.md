# 我的意图

我使用电子信息设备，是为了获取有价值的信息、完成明确任务，而不是让自己在无意识的刺激中失控。这个文档是我给自己的约束协议，用来在日常中提醒和纠偏。

# 总体原则

- 我先控制自己，再使用设备。
- 我先确定目的，再接触信息。
- 我先打开记录，再打开设备。
- 我只在约定的时间窗内使用设备。
- 一旦发现自己失控，我立即停下并记录。

# 使用前-决策流程

每次想使用电子信息设备（手机、电脑、平板、游戏机等）前，我遵循以下步骤：

1. 问自己三个问题：
   - 我现在要做的事是什么？
   - 这个任务必须用电子设备吗？
   - 这件事对现在的我是否重要或必要？
2. 若回答不清楚或偏向“只是想刷一下、看一眼”，默认视为高风险行为，不进入设备。
3. 若确认需要使用设备，我先打开记录，再开始使用。

# 动作回路-先记录再使用

- 我固定使用一个记录入口来追踪所有“信息摄取行为”，包括：刷社交媒体、看视频、看新闻、浏览网页、玩游戏、聊天、查资料等。
- 动作顺序：
  1. 先打开记录表（或对应的记录文档）。
  2. 在记录中写下本次使用的关键信息。
  3. 设置好时间边界。
  4. 只有完成以上步骤，才能打开具体应用或设备。

## 记录内容（最少字段）

每次开始前，我至少记录：

- 时间：开始时间
- 设备与应用：例如“手机-微博”“电脑-B站”“iPad-微信阅读”
- 行为类型：查资料 / 工作 / 学习 / 娱乐 / 随机浏览
- 意图：一句话写清楚“我想要得到什么”
- 计划时长：本次计划用多少时间（例如 10 分钟、25 分钟、50 分钟）

结束后，我补充：

- 实际时长：实际花了多久
- 结果：有没有完成一开始的意图
- 状态：结束时的感受（清醒 / 空虚 / 焦虑 / 停不下来等）

# 时间控制-边界设置

- 我为不同类型的使用设置默认上限：
  - 娱乐型：单次不超过 20 分钟。
  - 学习型：单次不超过 50 分钟，中间必须离屏 5 分钟。
  - 工作型：按任务块设置时间，而不是一直挂着应用。
- 在使用前，我给自己一个清晰的“结束点”，例如：
  - 看完这 1 个视频就停。
  - 查到 3 个可靠来源就停。
  - 完成这 1 个具体任务就停。
- 一旦达到时间或结束点，我立刻退出应用，不再“顺手多刷几下”。

# 失控识别-何时算失控

出现以下任一情况时，我视为“已经或正在失控”：

- 明明说好只看一会，时间明显超出计划。
- 在不同应用之间来回切换，却没有清晰任务。
- 关闭应用后立刻又下意识点开。
- 只是为了填补无聊、焦虑、空虚，而不是为了解决问题。
- 明知道明天会后悔，但此刻仍停不下来。

一旦识别到这些信号，我遵循以下动作：

1. 立刻退出当前应用或锁屏。
2. 在记录表中标记“失控”，简短写下：
   - 当时在做什么
   - 大约持续了多久
   - 此刻的真实感受
3. 做一个完全不接触屏幕的动作（喝水、深呼吸、走动、冷水洗脸等）。

# 信息摄取-全量记录原则

- 原则：凡是“主动摄取信息”的行为，都尽量纳入记录。
- 包括但不限于：
  - 刷短视频、看直播、看剧、看电影
  - 刷社交媒体、社区帖子、评论区
  - 看新闻、博客、长文章
  - 娱乐型游戏、休闲小游戏
  - 随机搜索、瞎点推荐内容
- 即便是“只是看几眼”，也要尽量留下痕迹，让自己有机会回头看到真实的使用情况。

# 安全模式-高风险状态下的限制

在以下状态下，我默认启用“安全模式”，尽量不使用电子信息设备，或只在严格限定情境下使用：

- 极度疲惫、熬夜、情绪很糟、焦虑爆棚的时候。
- 刚经历重大挫折、冲突或情绪事件时。
- 已经连续多次在同一天里失控时。

安全模式下的规则：

- 不打开短视频类、社交媒体流式信息类应用。
- 如非必要，不在床上使用手机或平板。
- 如必须用设备，只用于单一清晰任务，用完即关机或远离。

# 例外与调整

- 若因为工作、学习必须长时间在线，我在开始前明确标记“工作/学习”性质，并尽量拆分为多个时间块，中间安排离屏休息。
- 若出现特殊情况（例如远程会议、重要沟通），允许放宽时间限制，但必须在事后回到记录中做一次简短复盘。

# 自我复盘-如何用这个协议

- 每天结束前，我快速浏览当天的记录：
  - 有没有超时特别严重的行为？
  - 哪些应用最容易让我失控？
  - 哪些时段是高风险时段？
- 每周至少一次，我根据实际情况微调：
  - 时间上限是否需要收紧或放宽
  - 哪些应用需要临时卸载、禁用或隐藏
  - 是否需要在物理环境上做调整（例如远离床、设定充电位置）

# 对自己的承诺

- 我承认自己容易在电子信息设备前失控，所以我需要约束。
- 我承诺：在打开高刺激信息应用前，先经过记录和时间设置。
- 我承诺：当我发现自己骗自己时，不自责，而是通过记录和调整来修正。
- 这个协议不是一次性写完的规则，而是我与自己持续谈判、更新的边界。
