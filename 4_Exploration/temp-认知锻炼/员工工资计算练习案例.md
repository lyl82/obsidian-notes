## 🎯 练习案例设计：某科技公司月工资核算

### 一、公司背景设定（真实还原）

**公司性质**：互联网科技公司，150人左右，实行**弹性工作制+核心工作时间**  
**薪资结构**：固定工资（70%）+ 浮动工资（30%）  
**发薪日**：每月15日发放上月工资  
**考勤周期**：自然月（1日-月末）

### 二、核心数据表结构（11张表的真实场景）

基于真实HR系统架构 ，你需要处理以下数据关系：

#### **表1：员工基本信息表**（15人样本）
| 字段 | 说明 |
|------|------|
| 员工ID | E001-E015 |
| 姓名 | 真实姓名 |
| 部门 | 技术部/销售部/行政部/产品部 |
| 岗位序列 | 行政序列/技术序列/营销序列（不同序列系数不同） |
| 工资标准（薪级） | 根据职级确定基数，如3000-15000元 |
| 入职日期 | 影响工龄工资计算 |
| 银行卡号 | 最终输出用 |

#### **表2：薪资基础表**（固定部分）
包含：基本工资系数、技能工资系数、住房补贴、医疗补贴（固定工资合计系数0.7）

#### **表3：考勤原始数据表**（打卡记录）
- 每日上下班打卡时间
- 迟到/早退分钟数
- 缺卡、补签记录
- **关键规则**：迟到>30分钟按旷工半天计 

#### **表4：请假申请表**
- 请假类型（事假/病假/年假/婚假）
- **重要**：年假不扣工资，事假按天扣减，病假扣减50% 

#### **表5：加班申请表**
- 工作日加班（1.5倍）
- 周末加班（2倍）
- 法定节假日加班（3倍）

#### **表6：绩效考核表**
- 考核等级：S(1.3)/A(1.1)/B(1.0)/C(0.6)/D(0) 
- 部门分布强制比例：S-5%, A-15%, B-60%, C-15%, D-5%

#### **表7：社保公积金基数表**
- 个人缴纳比例：养老8%+医疗2%+失业0.5%+公积金10% 
- 缴费基数上下限（按当地标准）

#### **表8：专项附加扣除表**
- 子女教育、房贷利息、赡养老人等

#### **表9：月度考勤汇总表**（需计算生成）
- 应出勤天数（扣除周末和法定节假日）
- 实际出勤天数
- 迟到次数/累计分钟
- 各类假期天数

#### **表10：工资计算明细表**（核心产出）
包含40+个字段的完整计算链

#### **表11：银行报盘表**（最终输出）
格式：`银行卡号|实发金额|姓名`

### 三、复杂计算逻辑（真实业务难点）

#### **难点1：浮动工资系数计算**
```
固定工资 = 工资标准 × 0.7
浮动工资 = 工资标准 × 0.3 × 考勤系数 × 绩效系数 × 效益系数
```
- **考勤系数计算规则** ：
  - 旷工0.5天以上 → 扣除全部考勤工资
  - 病/事假每1天 → 扣除考勤工资0.25
  - 迟到/早退累计5次 → 扣除0.5
  - 迟到/早退累计1小时 → 扣除0.5

#### **难点2：个税累计预扣法**（真实算法）
不是简单的单月计算，而是**累计收入-累计免税收入-累计减除费用-累计专项扣除-累计专项附加扣除**后按累计税率表计算 

#### **难点3：跨表数据匹配**
- 需要关联11张表
- 处理缺失值（如某员工无加班记录、无请假记录）
- 日期匹配（判断打卡记录是否在工作日）

### 四、真实异常场景（故意设置的数据问题）

为了让练习更真实，我会加入以下**数据质量问题**：

1. **打卡异常**：某员工3月15日只有上班打卡无下班打卡
2. **跨月请假**：某员工3月31日-4月2日请假，需判断3月部分
3. **绩效争议**：某员工绩效等级为C，但部门负责人备注"特殊情况"
4. **社保基数调整**：3月有新员工入职，按首月实际工资缴纳
5. **个税跳档**：某员工累计收入刚好跨越税率级距
6. **银行账号错误**：某员工银行卡号少一位（需校验）
