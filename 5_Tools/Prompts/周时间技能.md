# 技能名称
原始时间日志可视化大盘生成 (RawTimeLog_to_VisualDashboard)

# 技能目标
将非结构化或半结构化的原始时间日志（文本/CSV），通过数据清洗与聚合，转换为基于 HTML + Tailwind CSS + ECharts 的单文件“驾驶舱级”可视化大盘，使用户对时间去向“一目了然”。

# 适用范围
- **适用**：含有“日期、事件、时长”的时间记录数据（如 Obsidian/CSV 日志）；希望零基础直接运行并查看结果的场景（不需要配置 Node.js/NPM 等环境）。
- **不适用**：百万级以上数据量（需要后端数据库）；需要动态双向修改原始数据的系统（单文件 HTML 只读）。

# 输入
- **必须输入**：原始时间日志文本或文件（需包含：日期时间、事件名称、耗时分钟数）。
- **可选输入**：用户期望的聚类维度（如“把物理移动和散步算作身体类别”），看板主题偏好（深色/浅色）。
- **缺失时的补问模板**：
  “你提供的时间日志缺失了[耗时时长/具体日期]信息，请补充。或者你是否需要我通过首尾时间戳帮你自动计算耗时？”

# 输出
- **交付物**：一个 `.html` 文件。
- **格式要求**：
  1. 使用 CDN 引入 Tailwind CSS 和 ECharts，无需本地依赖。
  2. 时间单位统一转换为小时（h），保留 1 位小数（如 12.0h）。
  3. 必须包含三个维度的图表：全局占比（甜甜圈图）、面积占比（树图/Treemap）、每日趋势（堆叠柱状图）。

# 执行步骤
1. **目的：数据清洗与分类**
   - **操作**：解析用户提供的原始文本，提取出 `日期`、`事件`、`耗时`。将高频事件合并为宏观大类（如求职、运动、娱乐）。
   - **判断条件**：若某事件占比极小（<1%），则归入“生活杂务”或“其他”；若存在大段未记录时间，统一标记为“未记录/碎片”。
   - **产出**：JSON 格式的分类汇总数据。
2. **目的：构建 HTML 与 UI 骨架**
   - **操作**：使用 Tailwind CSS 编写深色网格系统（Grid），顶部为 KPI 卡片，中间并排两张图表，底部为趋势图。
   - **判断条件**：若屏幕宽度较小，Grid 自动降级为一列（响应式设计）。
   - **产出**：静态 HTML 框架。
3. **目的：注入图表与数据（ECharts）**
   - **操作**：编写 JavaScript，初始化三个 ECharts 实例。将步骤 1 的数据映射到 `series.data` 中。配置统一的 `color` 调色板确保视觉一致性。
   - **判断条件**：数字是否以分钟为单位？若是，除以 60 并 `.toFixed(1)` 转换为小时。
   - **产出**：带有动态渲染和 Tooltip 的单文件大盘。

# 决策逻辑
- **如果** 用户日志极其碎片化（如上百个不同标签），**则执行** 聚类降维，强行合并至 5-7 个核心大类，避免图表变脏。
- **如果** 某天的总记录时长低于 24 小时，**则执行** 补齐逻辑，将剩余时间填充为“未记录/黑洞”，确保总趋势图堆叠柱的高度大致平衡。
- **如果** 用户没有提供设计偏好，**则改用** 深色科技风（Slate-900 背景，Cyan/Blue 主色调），符合“驾驶舱”直觉。
- **如果** 输入数据量太少（仅 1 天），**则** 取消“趋势图”，替换为“事项列表”。

# 质量标准
- **完成**：生成一个能用浏览器直接打开、无报错、有数据的 HTML 文件。
- **高质量**：颜色搭配和谐（Tailwind色系），所有卡片和图表随窗口大小自动缩放（resize），时间单位换算准确无误，代码结构清晰、自带注释。
- **不合格**：需要安装 npm 依赖才能看；使用了过时的 HTML 绘图方式（如手写 SVG 算坐标）；数据加总与原始日志对不上。

# 常见错误
1. **图表不显示（高度为0）**：ECharts 容器必须指定确定的宽高（如 `h-[300px]`）。修复：在 div 上加上明确的高度类名。
2. **中文字符乱码**：HTML 未声明 charset。修复：在 head 补充 `<meta charset="UTF-8">`。
3. **未记录时间被忽略**：导致“我时间花哪了”变成幸存者偏差。修复：总时间必须以物理时间为基准，将差值强行作为“未记录黑洞”呈现。

# Prompt 模板

**1. 完整版（面向普通 AI）**
> 你是一个高级前端工程师和数据分析师。我有一份时间日志数据（附后）。请执行「原始时间日志可视化大盘生成」技能。
> 要求：
> 1. 先清洗数据，聚类出 5-7 个核心类别，计算耗时（转为小时 h）。
> 2. 补齐“未记录时间”。
> 3. 写一个单文件 HTML，引入 Tailwind CSS 和 ECharts CDN。
> 4. 实现深色驾驶舱风格（Cockpit）。
> 5. 必须包含：顶部 KPI、全局占比饼图、面积树图、每日堆叠柱状图。
> 请直接输出完整的 HTML 代码。
> [在此粘贴数据]

**2. 简化版（用于日常复用）**
> 将以下时间日志数据转换成单文件 HTML 驾驶舱大盘（用 Tailwind + ECharts，深色风，单位：小时 h）。
> [在此粘贴数据]

**3. 给低能力模型的强约束版**
> 严格按以下指令执行：
> 1. 把下面的文本里的分钟数全部加起来，除以 60，得到“总小时数”。
> 2. 告诉我哪些事情花的时间最多。
> 3. 写一段 HTML 代码，必须在 `<head>` 里放 `<script src="https://cdn.tailwindcss.com"></script>` 和 `<script src="https://cdn.jsdelivr.net/npm/echarts@5.5.0/dist/echarts.min.js"></script>`。
> 4. 给出一个包含图表代码的完整文件，不要省略任何 JS 代码，确保可以直接运行。

# 示例
**输入**：
“今天 10:00 散步 60分钟；12:00 面试 120分钟；15:00 写代码 180分钟”
**输出**：
- 总时间：6.0h
- 运动：1.0h，职业：2.0h，工作：3.0h。未记录：18.0h（按24h算）。
- （产出对应的包含 KPI 和三个 ECharts 图表的单文件 HTML 代码块）
