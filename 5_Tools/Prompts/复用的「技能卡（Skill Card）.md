1、将这里的需求请把我们刚完成的任务，提炼成一份可机器复用、可人类复用的「技能卡（Skill Card）」。

目标：
这份技能卡将提供给：
1. 未来的我自己
2. 能力较弱、上下文理解有限的 AI
3. 需要重复执行同类任务的执行者

请输出时遵循以下原则：
- 不复盘聊天，而是提炼任务方法
- 不描述偶然细节，而是提炼稳定流程
- 不依赖高手直觉，而是显式写出判断依据
- 不只说“做什么”，还要说“为什么这样做”
- 让新手也能按文档完成任务

请使用以下结构输出：

# 技能名称
给这个任务起一个简洁明确、可检索的名字

# 技能目标
说明这个技能解决什么问题，最终交付什么结果

# 适用范围
说明适用于哪些任务，不适用于哪些任务

# 输入
列出执行该任务所需输入，并区分：
- 必须输入
- 可选输入
- 缺失时的补问模板

# 输出
列出标准输出应包含什么，格式要求是什么

# 执行步骤
按顺序给出完整流程，每一步包含：
- 目的
- 操作
- 判断条件
- 产出

# 决策逻辑
把关键判断写成规则，例如：
- 如果 X，则执行 A
- 如果 Y，则改用 B
- 如果信息不足，则先补问，不要继续生成

# 质量标准
定义什么样算完成，什么样算高质量，什么样算不合格

# 常见错误
列出执行该任务时最常见的问题、误区和修复方法

# Prompt 模板
输出 3 套模板：
1. 完整版
2. 简化版
3. 给低能力模型的强约束版

# 示例
提供至少 1 个完整输入输出示例

# Markdown 存档版
最后输出一版可直接保存到知识库中的 markdown 正式版
