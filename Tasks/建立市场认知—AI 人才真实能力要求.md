## Task 03 · 建立市场认知——AI 人才真实能力要求

---

- [ ] **Task 03 · 市场对 AI 人才的真实能力要求** 📅 2026-04-11

### 目标

搞清楚现实市场如何定义"AI 人才"，提炼出可量化的能力模块，并完成一次自我对照。

### 可交付结果

- [ ] 一份《AI 岗位能力地图》，包含 5～8 个核心能力模块
- [ ] 一份《个人能力对照表》，标注已有 / 空白 / 感兴趣三类
- [ ] 一条结论：市场最稀缺的 AI 能力是什么

---

### 完成标准

- [ ] 收集不少于 20 个 AI 相关岗位描述
- [ ] 覆盖至少 3 种岗位类型（技术 / 产品 / 运营方向）
- [ ] 能力模块提炼完成，每个模块有 2～3 个具体技能描述
- [ ] 个人对照表已填写，有明确的"下一步要补的"标注

---

### 现实动作

#### 第一步：收集岗位样本
- [ ] 在招聘平台搜索以下关键词，各取 4～5 条
	- [ ] `AI engineer`
	- [ ] `AI产品经理`
	- [ ] `Prompt engineer`
	- [ ] `AI automation`
	- [ ] `LLM application`
- [ ] 平台覆盖：国内平台（Boss直聘 / 拉勾）各半

#### 第二步：提取关键词
- [ ] 逐条阅读 JD，划出反复出现的技能词
- [ ] 汇总成一个词频列表，出现 3 次以上的重点标注

#### 第三步：归纳能力模块
- [ ] 将关键词聚类，归纳成 5～8 个能力模块
- [ ] 每个模块写出：模块名 + 具体技能 + 市场需求频率

#### 第四步：个人对照
- [ ] 对每个能力模块做三级标注
	- [ ] ✅ 已有基础
	- [ ] ⬜ 完全空白
	- [ ] ⭐ 感兴趣想深入
- [ ] 找出你的"最大空白"和"最强兴趣"各一个

#### 第五步：写出结论
- [ ] 市场最看重的前 3 个能力是什么
- [ ] 你和市场期望之间最大的 gap 在哪里
- [ ] 基于这次分析，你下一步最值得投入的方向是什么

---

### 备注

> 这个任务的核心不是"知道市场要什么"，而是第一次用外部现实来校准你自己的认知方向。完成后你会对"我该往哪里走"有一个比现在清晰得多的答案。
