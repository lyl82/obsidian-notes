## Task 05 · 找到 3 个用 AI 赚钱的真实案例并分析

---

- [ ] **Task 05 · AI 商业化真实案例分析** 📅 2026-04-18

### 目标

建立"AI 如何转化为收入"的具体认知，找到可观察、可拆解的真实商业模式样本。

### 可交付结果

- [ ] 3 个真实 AI 赚钱案例的完整分析记录
- [ ] 一张《AI 商业模式对照表》，横向比较 3 个案例
- [ ] 一条个人判断：哪种模式对你最有参考价值，为什么

---

### 完成标准

- [ ] 3 个案例必须真实，有可验证的收入形式（订阅 / 服务费 / 信息产品 / API调用费等）
- [ ] 每个案例完成 5 个维度的分析
- [ ] 对照表已完成，能横向看出三者的差异
- [ ] 个人判断已写出，不少于 3 句话

---

### 现实动作

#### 第一步：找到 3 个案例
- [ ] 搜索渠道
	- [ ] Twitter/X 搜索 `AI side project revenue`、`built with AI`、`$MRR AI`
	- [ ] Reddit 搜索 `r/SideProject`、`r/entrepreneur` + AI 关键词
	- [ ] 独立开发者社区：Indie Hackers、Product Hunt
- [ ] 筛选标准
	- [ ] 有明确收入数字或收入形式
	- [ ] 能看到产品本身或服务描述
	- [ ] 不是大公司，优先个人或小团队

#### 第二步：逐案例分析（每个案例填以下 5 个维度）
- [ ] 案例 1
	- [ ] 它在卖什么
	- [ ] AI 在哪里介入、做了什么
	- [ ] 它替代了什么原有成本
	- [ ] 客户为什么愿意付钱
	- [ ] 这个模式的门槛和天花板在哪里
- [ ] 案例 2（同上）
- [ ] 案例 3（同上）

#### 第三步：完成对照表
- [ ] 建一张表，列：案例名 / 收入模式 / AI 角色 / 核心价值 / 可复制难度
- [ ] 横向比较三者，找出共同点和差异点

#### 第四步：写出个人判断
- [ ] 这三个案例里，AI 最常在哪个环节创造价值
- [ ] 哪种模式门槛最低、最容易起步
- [ ] 哪个案例和你自己的兴趣或能力最接近

---

### 备注

> 这个任务的核心不是找"最成功的 AI 项目"，而是找"能看清楚商业逻辑的样本"。案例不需要大，逻辑清晰比规模重要。完成后你会第一次对"AI 怎么赚钱"有具体而非抽象的理解。
