## 做出一版职业顾问咨询用个人 Context 📅 2026-04-15

---

### 目标（可交付结果）

- [x] 完成一份结构化的个人 Context 文档：任何人（真人顾问 / AI / 你自己）拿到后，无需追问即可理解现状、资产与目标方向。 ✅ 2026-04-16

---

### 完成标准（可判断）

- [x] 已覆盖：经历、能力、现实处境、目标方向四个模块，每块至少有 3 条实质内容 ✅ 2026-04-28
- 已做到：每一条都是具体事实或具体判断，没有"可能""也许""大概"这类模糊表述
- 能做到：把这份文档直接发给一个陌生顾问，对方不需要再问"你的背景是什么"
- 验收标准：你自己读完一遍，没有觉得"这句话我其实不确定"的地方

---

### 现实动作（按阶段触发）

🔴 阶段 1：搭骨架（触发：现在，打开一个空白文档就启动）

- [x] 复制下方四个模块标题，建立空白文档结构： ✅ 2026-04-14
  - 【A. 经历事实】
  - 【B. 能力盘点】
  - 【C. 现实处境】
  - 【D. 目标与底线】
- 在每个模块下写 1 句话：你现在对这块最确定的一件事
- 不求完整，只求每块都有至少一个锚点落地
- 完成信号：四个模块都有字，哪怕每块只有一行

🟡 阶段 2：填肉（触发：阶段 1 完成后，下一个你有 30 分钟连续时间时启动）

- 【A. 经历事实】：按时间顺序，列出所有做过的岗位/行业，每条写：做了多久 + 主要在做什么事
- 【B. 能力盘点】：分两列填写——"我确认自己会的"和"我确认自己不会/很弱的"，各写 3 条以上
- 【C. 现实处境】：填写以下 4 项
  - 现在经济压力等级（紧迫 / 有缓冲 / 暂时托底）
  - 每天稳定可投入时间（小时）
  - 地理位置 + 能否接受远程/异地
  - 身体和精力的真实描述（用你自己的话，不美化）
- 【D. 目标与底线】：填写以下 3 项
  - 我想去的方向（哪怕现在只是感觉，也写下来）
  - 我对工作最低的要求是什么（不能接受什么）
  - 钱、稳定、自由、意义，我现在的排序
- [x] 完成信号：每个模块都有 3 条以上实质内容 ✅ 2026-04-14

🟢 阶段 3：收口（触发：阶段 2 完成后，间隔至少 1 小时再启动）

- 从头读一遍，把所有"可能""也许""大概"替换成具体表述，或直接删掉
- 检查有没有自相矛盾的地方，有就加一行备注说明
- 在文档顶部写一段 3 \~ 5 句话的"总述"：我是谁 + 我现在在哪 + 我想去哪
- 完成信号：总述写完，你读完觉得"这就是我现在的情况"

🔵 阶段 4：验收（触发：阶段 3 完成后）

- 把文档发给 AI（或顾问），第一句话说："这是我的背景，请基于这份材料给我职业建议"
- 看对方是否还需要追问基本信息
- 如果追问超过 2 个问题，回到对应模块补充，直到不再被追问
- 完成信号：对方基于这份文档给出了实质性建议，未追问基本背景
