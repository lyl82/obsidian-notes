# 触发链路图谱（版本1）

## 主链A：节律错位 → 冷 → 盆底张力 → LSE放电
- 晚睡/疲劳 → REM提前 → 脚/下肢冷 → 骶段兴奋↑ → 盆底高张力未释放 → 射精反射 → 遗精/外溢

## 主链B：性输入预加载 → 睡前激活 → 低抑制窗口
- 白天性输入高 → 睡前联想滚雪球 → 前额叶抑制下降 → 旧性记忆模板被调用 → 外溢/遗精

## 主链C：清晨峰值 → 梦境情绪 → LSE同步
- 睾酮晨峰 + 皮质醇回升 → REM比例高 → 情绪梦 → LSE激活 → 遗精

## 惊恐变体链
- 遗精后敏感期 + 入睡前交感残余 → 内感受放大 → 边缘系统报警 → 惊恐发作

## 观测要点
- 记录链路对应的参数组合，形成个人“链路—参数映射表”。
